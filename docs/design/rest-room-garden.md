# 休憩所＝自分の部屋（2026-09-12 Kevin の案、Claude が最小の形に）

## Kevin の言葉（9-12）
休憩所が自分の部屋のように、オブジェがあって。植木鉢の木を芽から水をかけて育てる。5個くらいの木。壁に太陽の絵を飾る。プレイでハートか何かを稼いで、休憩所でじょうろ・水・絵画に交換して飾る。エンディングの見た目が部屋と連動：太陽の絵を飾るとエンディングで夜明けが来て日が昇る、木を育てるとエンディングで木が伸びる。

## 類似作品（型の確認）
- どうぶつの森・ぼくのなつやすみ：部屋と庭を少しずつ飾る。飾りが「思い出」になる
- Hades（館の改装）・Stardew（農場）：稼いだものを拠点に注ぎ、拠点が育つ
- Celeste／Journey：エンディングが道中の行いで変わる（Journey は服の模様、Celeste はいちごの数）
- 型：**稼ぐ → 拠点で交換 → 拠点が育つ → 最後に世界が拠点の形に「なる」**。Kevin の案：休憩所で作ったものが、クリア後の浄化された地上の景色になる（Okami の浄化＋どうぶつの森の部屋）
