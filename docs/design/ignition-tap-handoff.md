# 点火を「タップの調子」にする案 — 設計スレへの持ち込み（2026-09-16）

デザインスレ（見た目）で出た話が遊びの変更に踏み込むので、設計スレに渡す。
**ここに書いてあるのは Kevin の発想とデザイン側の材料。決定ではない。** 決めるのは設計スレと Kevin。

## 1. 何を頼むか
点火を「隣に立って時間を待つ」から「タップ（クリック）を調子よく打つ」に変えるかどうか、変えるなら中身をどうするかを設計してほしい。
祭壇を2種類（石皿・吊り灯籠）にして、点火の調子を系統として変える案も含む。

## 2. Kevin の発想（9-16、要点）
- 石皿と灯籠を**両方採用**して、点火の仕方が違う、でもいい。灯籠はジャンプとか。
- 横に立つだけでなく、**リズムよくタップかクリック**しないと点火しない。火を起こす、マッチをする感覚。
- **たまになかなかうまくいかなくて、もどかしい**のがあってもいい。
- 調子は石皿と灯籠で**一貫して系統として違う**。
- そうなるとエフェクトは、火花が散る／小さな灯りがポツポツしだす、になる。時間経過じゃなくなるから。

## 3. 今の仕組み（コードの事実、`game/underborn_scout8m.html`）
- 祭壇の隣に立ち止まると `takeT` が溜まり、`igniteNeed()` に達すると点火。`takeSec=1.4` 秒。
- 進化段階で短縮：段階2＝×0.85、段階3＝×0.5、段階4（真の姿）＝**即時**。
- 暗火コア：消灯したまま点火できる。点火時に残り時間が半減。
- 種火配下：祭壇に着くと**勝手に灯す**（連鎖）。プレイヤーの操作なし。
- 逃げる祭壇（5F など）：4秒止まって動く。灯すと止まる。
- 息止め中は光が消える。点火中の表示は「祭壇に火を移している」（暗火なら「暗火で灯している」）。
- 入力：タップは既にある（種火選択で祭壇をタップ）。キーは WASD／矢印。
- 点火中の見せ方は今「祭壇のまわりに輪のゲージ」。Kevin はこれを**そのまま残すのは微妙**と言っている。

## 4. 設計スレで決めてほしい問い
1. 時間待ち → タップの調子、に**変えるか**（変えない選択も含む）。
2. 変えるなら、「うまくいかない」は**運か、調子を外した自分のせいか**。住民が近い時に運で失敗すると理不尽に感じやすい。
3. 進化の短縮（×0.85／×0.5／即時）と、真の姿の「即時点火」をどう置き換えるか。例：必要な打数が減る、真の姿は1打。
4. 暗火（点火時間半減）と息止め中の点火の扱い。
5. 種火配下の連鎖点火は操作なしのまま？
6. 石皿と灯籠、**2種を採用するか**。採用するなら階ごとの配分（今は祭壇は全部同じ。逃げる祭壇だけ特別）。
7. 調子の系統。デザイン側の仮案：**石皿＝速い連打**（カッカッカッ、火打ち石）／**灯籠＝ゆっくり一定**（トン…トン…トン、揺らして火を移す）。灯籠に「ジャンプ」を使うなら、ジャンプ操作が今ないので新設になる。
8. 操作の教え方。文字で説明せず、タップごとの反応（火花／ポツ）だけで調子が分かるか。
9. 9-10 の「遊びは固まった」を1か所開け直すことになる。Kevin の1周プレイで確かめる前提でよいか。

## 5. デザイン側の材料（決まっていること／候補）
- 床と壁＝案B（大きな石板）確定。
- 祭壇の絵：候補は**石皿（案A）と吊り灯籠（案C）**。刻み石（案B）は Kevin が外した。
  `docs/design/altar-mockup.png`（`.html` あり）。
- 点火の瞬間（0.15秒、光と揺れ）と自分の火（金の炎＋火の粉）は **Kevin「よさげ」**。
- 点火までの見せ方：輪のゲージの代わりに3案 `docs/design/altar-charge-mockup.png`（炎が育つ／火の粒が渡る／物の中に溜まる）。
  タップ式にするなら、**石皿＝タップごとに火花が散り、当たりが続くと種火が育つ**、**灯籠＝タップごとに籠の中にポツ、ポツと灯りが増える**、が自然（粒＋物の中に溜まる、の合わせ技）。
- 様式：1ドット=2px、色は女神の12色＋床壁の灰、光は下のぼかし。

## 6. 進め方の提案（デザイン側から）
1. 設計スレが §4 に答えて、小さな便を1本書く（開発フラグで新旧切替、まず石皿の連打だけ）。
2. Kevin が1周遊ぶ。
3. 手応えがあれば灯籠の調子を決め、絵はデザインスレで仕上げる。
4. 見た目のまとめ便に祭壇2種の絵を入れる。
