女神 v2 — ベイビーと同じ部品（石の殻・亀裂の火・火の瞳）で組んだ、大地そのものの石の顔

本体の `mShell` / `mCracks` / `mEye` / `mBlink` / `drawPoemLines` をそのまま写し、CS=560 の実寸。人型ではない。手も殻片も無い。新しい色は無い。殻は動かず、動くのは瞬き・口の灯り・亀裂の脈動だけ。
進行の軸は「大きさ」ひとつ：開始（目の前）→ 初進化 → 2回目（遠い）→ 地上（地面そのもの。目が地面に開き、穴が口）。ボタンで切り替え。

黒画面の詩（開始／初進化／2回目）。本体の `drawOpeningPoem` と同じ黒と放射光。吹き出しは息止めの教えと同じ黒帯、文字は .028（改行は正典のまま）。しっぽの先は口の亀裂。
地上（森）。本体の `drawSurfaceWorld` の地面の上に、女神を地面そのものとして重ねる（地面より上は出ない）。穴が口。しっぽは穴へ。ベイビーは本体と同じ位置（H*.68）。
