# UNDERBORN 実装指示：第7A-hotfix便 v1

## 0. この指示書について

- 設計セッション：2026-08-08／7A納品後のKevin実プレイで判明した問題への対処
- 対象ファイル：`game/underborn_scout7a.html`（GitHub `kj-keeley/under-born` の main を正典とする）
- 出力ファイル名：`game/underborn_scout7ah.html`（scout7a.html は残すこと）
- 新機能なし。検証を可能にするための道具立てと、明らかな邪魔の除去のみ

### この便の役割

Kevinが7Aの中身を実際に確認できる状態にする。現状は遺跡4〜5階の縦長階（敵4体）で止まり、18階の進化と詩、断面図、`visibilitychange` を実プレイ確認できていない。

壊すな指定：光と息止め、種火連鎖、敵AI、マップ生成、`renderMasterBody`、7Aの階数・割合進化・詩と儀式の分離・真の姿・周回スケーリング。`P` の値は変更しない。

## 1. 前提

- 初回スポットライト（`startFirstSpotlight`, `spotlightAnim`）と断面図（`drawCrossSection`）は定義だけで呼ばれていないものとして共有された。
- 実装時のコード照合では、スポットライトは `finishPoem()` から呼ばれていることが判明。断面図は `show()` の第4引数が真の時だけ描画されるが、実呼び出しに真がない。

## 2. 実装ステップ

### チャンク1

1. デバッグモードを、従来の `?dev=1` に加えて localStorage の永続フラグでも起動できるようにする。
2. タイトル画面の隅の連打などでフラグを切り替え、有効化と無効化の双方を用意する。
3. 判定は起動時の1回でよい。
4. チャンク1完了時に生存確認を報告し、返事を待たず続行する。

### チャンク2

デバッグパネルに、既存群と同じ見た目で次を追加する。

- 無敵：接触判定と捕縛処理を通さず、敵の上でもハートを減らさない。
- 段階直指定：1／2／3／自動。真の姿の既存トグルは変更しない。
- 敵ゼロ：有効化時に既存敵を消してよく、以後の階で敵を生成しない。

### チャンク3

1. 特殊階（縦長・L字・大広間）は `floor/FLOORS >= 0.25` の階だけに出す。特殊階の敵数（4／5／6）は変えない。特殊敵タイプの3階以降制限は変えない。
2. タブとタイトル画面から副題を削除する。
3. タイトル開始後の `titleExit` 中に再クリックまたはキー入力した場合、演出を即終了して次へ進む。1回目は従来どおり開始、2回目以降がスキップ。

## 3. 便全体の完了条件

- デバッグ無敵を有効にし、遺跡18階へ到達できる。
- 18階で進化儀式が起き、暗転後に詩「大きくなりましたね、小さな火。」が単独表示される。
- 表示されない場合は原因を調査し、`finishEvolutionSequence(true)` の経路が先に発火していないかを確認する。

## 4. スコープ外

- `P` のバランス数値、階数の再検討
- 7B：地図トグル廃止とミニマップ、タイトル孵化、開始詩、断面図の表示場所、スポットライト接続、クリア保存、地上演出、森コア
- 7C：支点一式

## 5. 最終報告で確認すること

- 18階の詩が表示されたか。表示されない場合は原因。
- 特殊階が25%以降で妥当か。
- 縦長階の敵4体が、13階以降でも多すぎるか。
- 定義があるが呼ばれていない関数。

完了報告は「反映／見送り／質問」の3区分。改善案は実装せず「提案」に分離する。
