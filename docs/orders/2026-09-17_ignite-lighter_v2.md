## 0. この指示書について
- 対象：`game/underborn_scout8n.html`（`2aaa2b8`）→ **出力 `game/underborn_scout8o.html`**
- Kevin の 8n 感想（9-17）：①拍が難しくてなかなか点かず、その間に配下が来て点けてしまう ②配下が別の祭壇を点けるとズームアウトして拍が分からなくなる ③「火花」などの文字はエフェクトに ④灯す前から青い炎があるのはおかしい ⑤音なしでも分かるように ⑥0.28秒は早すぎ・忙しすぎ ⑦**かなり簡単でいい。1〜2秒あればだいたい点く**
- ②の原因（Claude 確認）：`updateTapIgnition` の `eligible` が `chainPause<=0` を要求し、連鎖ポーズ（L1910〜、1.5秒＋カメラが引く）に入ると `resetTap()` で火花が全部0になる

### 壊すな指定
- `P.igniteMode==='wait'` の旧挙動、種火配下の連鎖点火（操作なし）、`sparkSelect`（送り先選択）、逃げる祭壇の動き、暗火・息吹の例外、`CANON_POEMS`、8n で入れた入力の優先順位・短いタップ判定・Enter リピート除外・`resetTap()` の呼び場所

## 1. 決定
| 項目 | 内容 |
| --- | --- |
| 型（Kevin 確定） | **世界の拍を無くす**。祭壇の隣で、**自分のテンポで叩く**（短いタップ／クリック／Enter。8n の入力判定をそのまま使う）。1回叩くごとに「カチ」と火花が散り、石皿の燠が1段育つ |
| 当たりの条件（暫定、かなり甘く） | 1打目・2打目は**必ず当たり**。3打目以降は、直前の間隔 `prev` に対して今回の間隔が **`prev×0.5`〜`prev×1.8`** なら当たり。外れ＝「乱れた」：鈍い音、燠が1段下がる（0未満にならない、全部は消えない）。**乱れた打は打刻 `tapLastT` を更新し、比較間隔 `tapPrevIv` を null に戻す**＝次の1打は必ず当たり、その次から比較を再開（指摘3）。**燠が0になったら `tapLastT`・`tapPrevIv` とも null**＝最初の2打からやり直し |
| 空振り | 前の打から **0.22秒未満**の入力は数えない（連打防止。減点なし、音なし）。`P.lighterMin=0.22`。**空振りは `tapLastT`・`tapPrevIv`・冷め時計のどれも更新しない**（指摘3）＝0.1秒連打でも、前の有効打から0.22秒たった打は有効になる |
| 冷める | 最後の打から **1.6秒**叩かないと燠が1段下がり、その後 0.8秒ごとに1段（`P.lighterCool=1.6`）。隣に立ったまま放置しても溜まらない。**冷め始めた（間隔が `lighterCool` 以上あいた）あとの最初の打は必ず当たり**で、`tapPrevIv` は null から測り直す（指摘3）。有効打・乱れ打で冷め時計を0に戻す |
| 必要数（暫定） | 段階1：**3**、段階2：**2**、段階3：**2**、真の姿：**1**。暗火は切り上げ半分（2・1・1・1）。`P.tapNeed` の既定を 3 に、`tapNeed()` は `st===4?1 : st>=2?max(1,need-1) : need`。目安：0.4〜0.6秒間隔で3打＝**約1〜1.5秒で点く** |
| 世界の拍の削除 | `tapBeat`・`tapWindow`・山の判定・飛ばしの減点・合図の「チッ」・`tapBeatDistance`・開発パネルの「拍の速さ」を削除。開発パネルは「点火：カチカチ／待ち」「必要数 1〜6」「空振り秒 0.1〜0.5」「冷める秒 0.8〜3」 |
| **連鎖ポーズで消さない（感想②、指摘1）** | **「進捗を消す条件」と「入力を受けない条件」を分ける**。①消す（`resetTap()`）＝隣接が切れる・対象が変わる・祭壇が動き出す・捕獲・通常コアの息止め・`buildFloor` 等（8n のまま）。**`sparkSelect` と `chainPause` は消す条件から外す**（`eligible` から `!sparkSelect&&chainPause<=0` を外す）。②入力を受けない＝`sparkSelect` 中だけ（送り先選択が先。8n のまま）。`chainPause>0` だけなら叩ける。③**保留中（`sparkSelect` または `chainPause>0`）は冷め時計を止め**、`tapHits`・`tapLastT`・`tapPrevIv` を保持する |
| **点火途中のカメラ（指摘2）** | `tapHits>0`（または下の `tapFx` が生きている）間は、①`chainView` を足さず**0へ戻す**（`chainView+=(0-chainView)*0.2`。既に引いていても通常倍率へ戻る）②**カメラの注視は点火対象（祭壇とベイビーの中点）を優先**し、`sparkRunner()` への追従・減速の寄りより先にする（配下の点火は `_claimFlash` と音で伝える）。`dt` の減速（0.85／0.32）自体は今どおりでよい（打の間隔は `rawDt`）。`tapHits===0` なら今どおり引く・追う。**連鎖演出が始まったあとに叩き始める場合**も、1打目が入った時点で①②に切り替わる |
| 青い炎を無くす（Kevin 確定） | 未点火の祭壇の冷たい青い火・青い光（L3018、L3035〜、ミニマップ L3217 の青）をやめる。**未点火＝火の無い石皿＋ごく弱い赤い燠**。燠の光は今の青と同じく**暗闇・壁越しでも見える**（場所の目印の役目を引き継ぐ）。明るさは今の青の半分程度。ミニマップの未点火は暗い赤茶（`rgba(150,80,50,.7)`）。絵は仮でよい（形は見た目スレで決める） |
| 燠が育つ（進み具合の表示） | `tapHits` に応じて石皿の燠が段階的に赤く大きくなる（0＝ごく弱い、必要数−1＝強い）。8n の「頭上の粒の列」は削除。点火で今の暖色の炎が立つ |
| **部屋が膨らむ（音なしで分かる、感想⑤）** | **演出状態を進捗から分ける（指摘5）**：`tapFx={pulse,sink,x,y}`。当たりで `pulse=1`（0.5秒で減衰）、乱れで `sink=1`（0.25秒）、`x,y` は祭壇とベイビーの中点をその時点で保存。**`resetTap()` では消さない**（点火成功の最後の1打＝真の姿の1打でも膨らみが描かれる）。消すのは `buildFloor`・モード切替だけ。`rawDt` で減衰し、`mode!=='play'` では止める。①**カメラを最大4%寄せる**（表示倍率に `1+0.04*pulse-0.015*sink`、`tapFx.x,y` へ）②**自分の光の半径と明るさの増減は描画専用（指摘6）**：`master.r`・住民の感知・配下の処理・`computeStatic` には触れず、光を描く所でだけ半径×`(1+0.12*pulse)`。**息止めで消灯している間（暗火の点火を含む）は光を増やさない**（寄りと粒だけ） ③画面の縁が暖色でふっと明るく。既存の `screenShake`・点火時の演出は今どおり |
| 文字の廃止（感想③） | 点火まわりの `markAt` の文字「火花」「・」を削除し、**火花の粒**（当たり：石皿から5〜7粒が散る／乱れ：灰色の粒が2〜3落ちる）に置き換える。点火成功の「灯」も粒と光だけにする。**他の文字（種火・転位・散・止など）は見た目のまとめ便で扱う＝この便では触らない** |
| 音と振動 | 当たり「カチ」＝`tone(1100,.035,'square',.07)`＋直後に `tone(520,.05,'triangle',.04)`。乱れ＝今の `tone(180,.08,'square',.05)`。スマホは当たりで `navigator.vibrate?.(12)`、乱れで `vibrate?.([8,40,8])`（未対応端末は無視） |
| 状態の文 | 「拍に合わせて 火を打つ」→ **「火を 打つ」**（暫定） |
| 逃げる祭壇・中断・初期化 | 8n のまま（止まっている間だけ／離れる・対象が変わる・捕獲・通常コアの息止めで0）。`resetTap()` に `tapLastT`・`tapPrevIv`・冷め時計の初期化を足す |
| 時計（指摘4） | **`tapClock`＝`mode==='play'` の間だけ `rawDt` を足し続ける単調な時計**（0へ戻さない。ポーズ・演出中は止まるだけ）。打刻・間隔・空振り・冷めはすべて `tapClock` で測る。**8n の `restartTapClock()` の「時計を0へ戻す」は廃止**（復帰で打刻との差が負にならないように）。`frame` の `tapFrameMode` 復帰処理と開発パネルのスライダーからの呼び出しは「`tapPrevIv=null` にするだけ」に変える。ポインタの短いタップは押下時の `tapClock` を打刻に使う（8n の `beatT` と同じ考え） |

## 2. 実装ステップ
### チャンク1：判定の置き換えと連鎖ポーズ
- `registerTap` を間隔判定に。`updateTapIgnition` から山・飛ばしを削除し、冷める処理を追加。`eligible`／`tapInputReady` から `chainPause<=0` を外す。`chainView` の条件
- 完了条件：1F で好きなテンポで3回叩くと点く（速め 0.3秒間隔でも、ゆっくり 0.8秒間隔でも）。0.1秒間隔の連打は空振りが混じるだけで減点されない。3打目を極端に早く／遅くすると1段下がる。放置で冷める。**配下が別の祭壇を灯しても燠が残り、続きを叩いて点けられる。その間カメラは引かず、点火対象が画面の中心付近に残る**。`sparkSelect` 中は叩けないが燠は残り、選択後に続きから叩ける。連鎖演出が始まってから叩き始めてもカメラが戻る。**2打のあとポーズして再開し、3打目が正しく判定される**
**ここでチャンク1完了報告。**
### チャンク2：見せ方（青い炎の廃止・燠・部屋が膨らむ・粒・音と振動）
- 完了条件：未点火の祭壇が暗闇で弱い赤として見つけられる。音を切っても、叩いた手応え（寄り・光・粒）と乱れが画面で分かる。文字「火花」「・」「灯」が出ない

## 3. 完了条件（便全体）
1. 新規開始 → 1F の最初の祭壇が、説明なしで 1〜2秒で点く（Sol の感触を1行）
2. 段階別の必要数 3/2/2/1、暗火 2/1/1/1
3. `wait` で旧挙動に完全に戻る（青い炎の廃止は両モード共通）
4. 連鎖ポーズ中に進み具合が消えない・叩ける・`tapHits>0` ならカメラが通常倍率へ戻り点火対象を映す。`sparkSelect` は今どおり動き、その間も燠は保持
4b. 真の姿（必要1打）でも当たりの膨らみが描かれる。膨らみで `master.r`・住民の感知が変わらない（息止め中は光が増えない）
5. 逃げる祭壇は止まっている間だけ。390px 幅で短いタップが効き、ドラッグで離れられる
6. 正典の詩は不変。`BUILD_VERSION='v0.8o'`
