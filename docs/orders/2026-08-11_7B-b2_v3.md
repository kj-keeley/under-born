## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| 息止め中の移動速度を独立した調整項目にする | 現在の息止めは「消えて動ける」ため、**見つかってから発動して逃げる**のが最適解になっている。隠れる必要がなく、透明化ダッシュとして機能している |
| 停止（0）まで下げられるようにする | 完全に止まれば、追われてから止めても無意味になり、**先に止めて待つ**しか使い道がなくなる。じっとしている時間そのものが遊びの本体になる |
| この便では既定値を変えない | 完全停止が理不尽になるか（曲がり角で鉢合わせたときに逃げ場がない）は、実際に触るまで分からない。数値で答えを出してから確定させる |
| 秒/マスではなく**比率**（0〜1）で持つ | 秒/マスを2本持つと、通常速度のスライダーを動かしたとき息止め中との関係が崩れる。比率なら維持される |
| **コアの固有能力は止めない。** 停止するのは通常の1マス移動だけ | 転位（位置交換）・霞（壁抜け）・暗火（消灯点火）はいずれも息止め中に使うことが前提の技。ここを潰すとコアの存在意義が消える |
| 速度の切り替えはマス単位に固定する | 移動の途中で速度が変わると、そのマスの移動が不自然に加減速する |

## 2. 棄却した案

**再提案しないこと。**

| 案 | 棄却理由 |
| --- | --- |
| この便で息止め中の移動を完全停止に固定する | 理不尽さの度合いが未検証。まずスライダーで探る |
| 息止め中だけ別の移動方式にする（1マスずつ、方向転換のみ等） | 既存の移動処理を分岐させることになる。速度の調整で足りるかを先に見る |
| 完全停止を `spt=Infinity` で実現する | `stepBy()`（L2514）は `master.tx/ty` を**先に**次のマスへ書き換え、`advance()` が見た目を補間する。`spt` を極大にすると `t` が進まない一方で `tx/ty` は移動済みになり、**見た目は止まっているのに当たり判定だけ移動している**状態になる |
| 完全停止を `spt=0` で実現する | `dt/0` により1フレームで移動が完了する。停止どころか瞬間移動になる |
| 息止め中はコアの固有能力も使えなくする | 上記のとおり、コアの取り分そのものを消すことになる |

## 3. 実装ステップ

### チャンク1（この便はチャンク1のみ）

#### Step 1: 息止め中の移動速度をスライダーに出す

**パラメータ**

- `P` に **`breathMoveRate`** を追加する。**秒/マスではなく比率**とする
  - 範囲：**0 〜 1**、刻み **0.05**
  - **初期値：1**（＝現在と挙動が変わらない）
  - `1` = 通常と同じ速度
  - `0` = 通常の1マス移動を受け付けない（完全停止）
  - 中間値の実効速度（秒/マス）＝ **`P.mSpeed / P.breathMoveRate`**
- `SPEC`（L2735 の「操作」グループ）に追加する。ラベルは `息止め中 移動比率` 等、比率であることが分かる名称にすること

**完全停止の実装方式（確定）**

- **`spt` を極大値や 0 にする方式は禁止。** `stepBy()`（L2514）は `master.tx/ty` を**先に**書き換えるため、`spt` を操作しても座標だけ移動してしまう
- **通常の1マス移動を、`stepBy()` が座標を変更する前に拒否すること。** `breathHeld` かつ `P.breathMoveRate === 0` のとき、通常移動として早期 return する
- **拒否するのは通常の1マス移動のみ。** 以下は従来どおり動作させること
  - **霞コアの壁抜け**（`stepBy()` 内、`isWall(nx,ny)` の分岐にある）— **同じ関数の中にあるため、雑に早期 return すると一緒に死ぬ**
  - **転位コアの位置交換**（配下タップ）
  - **暗火コアの消灯点火**
- 完全停止中も、向きの変更（`master.dir`）を許すかは実装側判断でよい

**速度の切り替え**

- `master.spt` は**そのマスの移動を開始する時点で決定し、移動中は変えないこと**
  - 移動の途中で息止めの開始・解除・スライダー変更が起きても、**そのマスは開始時の速度で完了する**
  - 新しい状態は**次のマスから**反映する
  - 完全停止へ変わった場合も、現在のマスを完了してから、次の通常移動を拒否する
- **既存の `mSpeed` スライダーの処理（L2807 `if(k==='mSpeed') master.spt=P.mSpeed;`）を見直すこと。** これは移動の途中でも `master.spt` を直接書き換えている。スライダーは `P` の値だけを変更し、`master.spt` は次のマスの開始時に決める形へ統一する

**完了条件**

- `breathMoveRate` を **1** にすると、息止め中も通常と同じ速度で動けること
- **0** にすると、息を止めている間**通常の移動入力では1マスも動けない**こと。かつ**通常の床方向への移動入力で `master.tx/ty` が変化しないこと**
  - ただし**コアの固有能力による座標変更は許可する。** `warp()`（L556付近）は `tx/ty/px/py/fx/fy` をまとめて書き換えるため、霞コアの壁抜けと転位コアの位置交換では座標が変化する。これは意図した動作
- 中間値（例 0.5）で、息止め中の移動が通常の半分の速度になること
- 息を吐いた後の復帰は**マス単位の切り替えに従うこと**
  - 完全停止していた場合：**次の通常移動から** `P.mSpeed` で動けること
  - 移動の途中で息を吐いた場合：**そのマスは開始時の速度で完了し、次のマスから**通常速度になること
- 移動の途中で息止めを開始・解除しても、そのマスの移動が不自然に加減速しないこと
- **完全停止（0）の状態で、霞コアの壁抜け・転位コアの位置交換・暗火コアの消灯点火が従来どおり使えること。3コアそれぞれで確認すること**
- `mSpeed` のスライダーを移動の途中で動かしても、そのマスの移動が破綻しないこと

## 4. 便全体の完了条件

デバッグモードで遺跡を数階プレイし、以下を確認すること。

1. `breathMoveRate` を**最小の 0**（＝完全停止）にした状態で、敵に追われながら息を止めても逃げられないこと
2. 同じ状態で、敵が来る前に息を止めて待てば、やり過ごせること
3. `breathMoveRate` を 1 に戻すと、従来どおりの挙動になること
4. `breathMoveRate` が 0 の状態で、転位・霞・暗火の3コアそれぞれの固有能力が使えること

**実装側の感触を報告に書くこと。** 特に、完全停止にしたとき曲がり角での鉢合わせが理不尽に感じるかどうか。
