## 1. 決定
| 項目 | 内容 |
| --- | --- |
| **A. 打つ瞬間のカットイン** | `completePinHold` の完了音「カーン」と同時に、**画面の上から断面図の板が差し込む**（黒の半透明の帯＋`drawCrossSection` を中央に、0.2秒でスッと降りる。暗転なし、盤面は後ろに見えたまま）。板が止まった 0.1秒後、**今の階の行に大きなハーケン（仮の絵：床の縄つきハーケン C を2.5倍に拡大した形）が上から「ドン」と打たれる**（0.15秒で落ちて着地、小さな揺れ `screenShake=0.25`、`tone(660,.08,'square',.09)` は既存の完了音を流用しそのまま）。着地後、**下にある直近の杭（0本目・休憩所の自動杭・前に打った杭）と縄で結ぶ線を 0.3秒で引く**（直近が無ければ縄なし）。合計 1.0秒見せて 0.2秒で上へ戻る。**この間は操作を止める**（`keys.clear()`、`held=false`、ポインタ無視。石皿・灯籠の判定は `mode!=='play'` 扱いで止まる＝新しい `mode='pinTopo'` を足すのが簡単。`tapClock`／`swingT` は止まる）。**飛ばせる**（Enter／タップで即戻る）。0本目の自動杭・休憩所の自動杭では出さない（手で打ったときだけ） |
| **断面図の杭の印** | `drawCrossSection` に「杭のある階」を渡し、その行の右に小さな杭の印（仮：`⚑` 相当の小さな三角）を常に描く。階カード・記録の石・旅の果てにも自然に出る。データ源：`activeRun.pin`（直近）と、**打った階の履歴 `activeRun.pinFloors=[...]`（新設）**。**保存と読込（指摘1）**：`saveRun` に含め、`normalizeRun()` にも項目を足す（整数の配列、1〜FLOORS の範囲、重複は除く、不正なら `[]`）。旧セーブに無ければ `[]`。新規ラン（`prepareRunFromBeginning`）で `[]` に初期化。**記録のタイミング**：手動の杭（`completePinHold`）、0本目の自動杭、休憩所の自動杭のすべてで、その階を追加（休憩所の杭は「休憩所の階＝入る前の階」として記録）。復帰で階が巻き戻っても履歴は残す。**旅の果てへの引き継ぎ（指摘2）**：`finishFinalAscent()` が `clearRun()` を呼ぶ前に `pinFloors` と直近の杭の階を結果用の変数（例 `endingStats.pinFloors`）へコピーし、地上演出→「旅の果て」の断面図はそれを使う。周回開始で消す |
| **C. 火が絶えたときのずり落ち** | **`pinRespawn.returnToPin` が真のときだけ**（指摘3。残り0本・杭なしで「はじめから」へ行く経路では `topo` を出さず今どおり）。`updatePinRespawn` の `candle` の後、`text`（「火が絶えた」）の後に **新しい phase `topo`**：真っ暗のまま中央に断面図。**小さな火（ベイビーの光の点）が今の階の行から直近のハーケンの階の行まで、行を1つずつ落ちる**（1行 0.12秒、途中で「カタ」`tone(220,.04,'square',.03)`）。杭の行で止まり、杭が一瞬光る（`tone(1320,.3,'sine',.05)`）。同じ階に杭があるときは落ちずに杭が光るだけ（0.5秒）。**表示範囲（指摘4）**：断面図は7行なので、落ち始めの階と杭の階の両方が入るように `drawCrossSection` に表示範囲（`low`）を渡せるようにし、**7行に収まらないときは火の行に追従してスクロール**（1行ずつ）。長さは「1行 0.12秒」を優先し、合計時間は行数に従う（上限なし。最長 15行＝1.8秒）。杭の光り 0.3秒＋余韻 0.3秒を足して次へ。**初回授与の経路（指摘5）**：初回は女神側が直接 `beginPinReturn()` を呼んでいる（`hakenLeave`）ので、**その呼び出しを「女神の入力処理を終えてから `pinRespawn.phase='topo'` に入り、`topo` の終わりで `beginPinReturn()`」に変える**。2回目以降は `text` の後に `topo`。**飛ばせない**（今の演出と同じ扱い） |
| **開発パネル** | `hakenGiftBtn`「渡す場面をもう一度」の**隣に「ハーケンを授与済みにする」を追加**：`campaign.hakenGiven=true; saveCampaign(); pinBtn.style.display='';`（本数は今の手持ち）。**Kevin 9-24 の混乱の対策**：授与は初めて火が絶えたときに女神から、が正規の道で、開発パネルから直接は無かった |
| 文言 | 帯「ハーケンを打った」は今のまま。断面図の上に小さく「遺跡 {n}F」（今の階カードと同じ書式） |

## 2. 実装ステップ
### チャンク1：A（カットイン）＋杭の印＋履歴＋開発ボタン
- 完了条件（指摘7：**新規開始は未授与なので、正規の順で確認する**）：新規開始 → 1F でわざとハート0 → キャンドル → 「火が絶えた」→ 女神がハーケンを渡す → **`topo`（同じ階なので杭が光るだけ）** → 復帰 → 1F で手動で打つ → **A** が出る（1F の行に大きな杭、0本目と同じ階なので縄なし、1秒で戻る、操作は止まり Enter で飛ばせる）。2F で打つと 2F の行に杭、1F の杭と縄。休憩所の自動杭では A は出ないが履歴には入る。階カード・記録の石の断面図に杭の印。再読み込み後も印が残る。**開発ボタン「授与済みにする」は別の確認**：新規開始直後に押すと HUD にハーケンが出て 1F で打てる
**ここでチャンク1完了報告。**
### チャンク2：C（ずり落ち）
- 完了条件（指摘6：休憩所の自動杭が復帰先を上書きするので階を変える）：**2F で打ち、3F でハート0** → キャンドル → 「火が絶えた」→ 断面図で火が 3→2 と落ちて 2F の杭で止まり光る → 杭の火→瞳→光で 2F の頭から。**別に「5F でハート0 → 4F 後の休憩所の杭へ」**：火が 5→（休憩所の行）へ落ちて止まる（休憩所の行の扱いは「4F の行」でよい）。同じ階なら落ちない。**残り0本でハート0 → `topo` は出ず「はじめから」**。開発「ハーケンへ戻るを試す」でも同じ順

## 3. 完了条件（便全体）
1. 新規開始→1F で打つ→A が出る（Sol の感触1行：気持ちいいか）
2. 2F 打ち→3F ハート0→C が出る。5F→休憩所の杭も。残り0本では出ない。初回の女神ありでも順が崩れない（女神→topo→復帰）
3. 断面図の杭の印が3か所（階カード・記録の石・旅の果て）に出る。再読み込み後も履歴が残る。旅の果ては `clearRun()` 後でも出る
4. 石皿・灯籠・息止め・4秒長押しの失敗条件は不変。390px 幅で断面図が画面内
5. `CANON_POEMS` 不変
