## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| **遺跡は16階**（`THEMES.ruins.floors=16`） | Kevin 確定 |
| **4区画×4階**：区画1＝1〜4F、区画2＝5〜8F、区画3＝9〜12F、区画4＝13〜16F | Spelunky の型。4階ごとに変わる＝Kevin の「3〜8階ごと」 |
| **区画ごとの地図**：区画1＝通常（今の遺跡の地図）、区画2＝L字、区画3＝縦長、区画4＝大広間。既存の特殊階3種を転用し、**遺跡の `SPECIAL_FLOORS`（13F・16F）は廃止** | 新しい絵を描かずに地形が4階ごとに変わる。Kevin「どこも同じ感じ」への直接の答え |
| **区画ごとの住民**：区画1＝基本3種（直進・巡回・分岐）、区画2＝＋ランダム型、区画3＝＋鈍足型、区画4＝＋速殺型。数は区画1＝2体、区画2＝3体、区画3・4＝4体 | 4階ごとに新顔の自己紹介が1回来る。今の「3階で特殊3種いっぺんに解禁」をやめる |
| **区画ごとの色**：既存の3段パレットを4段に（区画4用を1つ足す。実装側判断） | 変化が目で分かる |
| **休憩所**：4F・8F・12F を上がった直後（5F・9F・13F に入る前）に1つ。**階数に数えない**。住民なし、祭壇1つが最初から灯っている、その区画で正気に戻した住民が火のまわりに座って小さく上下、ハートが上限まで戻る、ハーケンを**消費なしで**打てる（打つと以後の復帰先）、穴が最初から開いていて自分で入ると次の階へ | Hades の休憩部屋・Hollow Knight のベンチ・マザー2 のホテル。記録の列（節目のカード）をここへ移す |
| **節目のカード（10・20…）は廃止**。住民の列は休憩所と地上とエンディングだけ | 16階に10F の節目は合わない。休憩所が代わり |
| **進化は 8F と 16F**：8F をクリアして休憩所を出て 9F に入るときに初進化（`child`）、15F をクリアして 16F に入るときに2回目（`lord`）。**遺跡だけ固定の階で判定**し、他の土地は今の割合計算のまま | 区画の境に合わせる。DECISIONS 09-09 暫定 |
| 16F クリア → 今どおり地上（遺跡は詩なし → 住民の列 → 穴の絵 → クリア画面） | 変更なし |

## 2. 実装ステップ

### チャンク1：16階・区画・地図・住民

#### Step 1: 階数と区画
- `THEMES.ruins.floors=16`。`zoneOf` は遺跡だけ `Math.min(3,Math.floor((f-1)/4))`（0〜3の4区画）。他の土地は今の3分割のまま（関数に土地の分岐を入れるか、`THEMES.ruins.zoneOf` を持たせる）
- `stageForFloor` は遺跡だけ `f>=16?3:f>=9?2:1`。他の土地は今の割合のまま
- `specialFloorAt('ruins',f)` は常に `null`（`SPECIAL_FLOORS.ruins` を空に）

#### Step 2: 区画ごとの地図
- `buildFloor` で遺跡のとき、区画に応じて `currentFloorShape` を選ぶ：区画1＝通常（`THEMES.ruins.map`＋`BASE_PATTERNS`）、区画2＝`lFloor(0)`、区画3＝`verticalFloor(0)`、区画4＝`wideFloor(0)`。特殊階の `enemyCount` は**使わず**、Step 3 の数を優先
- 断面図（`drawCrossSection`）は16階で描く（`FLOORS` を見ているなら自動）
- 完了条件：1F と 5F と 9F と 13F で地図の形が変わる。4F→5F の昇階カードの断面図が16段

#### Step 3: 区画ごとの住民
- `TYPE_MIX` を遺跡だけ4段に：区画1 `['I','L','T']`、区画2 `['I','L','T','R']`、区画3 `['I','L','T','R','B']`、区画4 `['I','L','T','R','B','H']`。**新顔が必ず1体入る**ように、区画の最初の階（5F・9F・13F）は新顔を先頭に置く
- 数：区画1＝2、区画2＝3、区画3＝4、区画4＝4（`baseEnemyCount` の遺跡分岐）。周回の＋1は今どおり
- パレット：`palette` を4段にし、区画で引く（`zoneOf` が0〜3を返すので添字がずれないよう確認）
- 完了条件：5F で初めてランダム型の自己紹介、9F で鈍足型、13F で速殺型

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：休憩所と進化

#### Step 4: 休憩所（`mode='rest'`）
- 4F・8F・12F の穴に入って `floorCard` のあと、`open` の代わりに **休憩所**へ。カードの文字は「遺跡 休憩所」（断面図の印は区画の境に小さな火）
- 盤面：小さな部屋（新しい地図 `makeRestMap()`、8×8 程度の一部屋。実装側判断）。中央に祭壇1つ（`mine=true` で灯っている）、その周りにその区画で正気に戻した住民（`activeRun.freedByFloor` の直前4階ぶん）が座って小さく上下、部屋の端に光の穴（`exitHole`）が最初から開いている
- 入った瞬間：`hearts=maxHearts`、帯に「ここは、しずかだ」（**暫定文言**。システムの声。女神の窓は使わない）
- ハーケン：この部屋で打つと**消費しない**（`pinAtMaster(true)` 相当）。復帰先はこの部屋（`activeRun.pin={floor:<次の階>,rest:true,…}` として保存し、復帰時は休憩所に戻る）。打たなくても、休憩所に入った時点で0本目相当の自動ハーケンをここに打ち直す（消費なし）
- 息止め・住民・タイマー・祭壇の点火判定は動かない（`floorCleared` を真にしておく）
- 穴に入る → `startAscent('rise')` → カードは「遺跡 5F」→ 5F（9F・13F も同じ）
- 保存：`activeRun.floor` は休憩所のとき次の階の番号、`activeRun.rest=true`。「つづきから」で休憩所に戻れる
- 完了条件：4F クリア → カード「休憩所」→ 静かな部屋、住民が火のまわり、ハート満タン、ハーケンを打っても本数が減らない → 穴 → 5F

#### Step 5: 進化を 8F→9F と 15F→16F に
- `nextFloor`／`startAscent` の進化判定（`stageForFloor(floor+1)>stageForFloor(floor)`）は Step 1 の遺跡用 `stageForFloor` で自動的に 9F と 16F になる。**9F は休憩所を出るときに儀式**：休憩所の穴に入る → 儀式 → 暗闇の声 → 女神 → 光で 9F。順番は「休憩所 → 進化 → 9F」
- 16F は 15F の穴に入る → 儀式 → 16F。16F クリアは今どおり地上
- 完了条件：9F と 16F に入るとき儀式と詩。それ以外の階では出ない

#### Step 6: 節目のカードの廃止と開発導線
- `milestone` の判定を遺跡では常に偽に（他の土地はそのまま）
- 開発パネル：「指定階へ移動」は16階まで、「休憩所を試す」（区画2の休憩所へ）を足す。「住民の列を試す」は休憩所の絵で
- 完了条件：10F のカードが普通の0.8秒
