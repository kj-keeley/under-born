## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| **最後の祭壇を灯しても自動では上がらない**。`pulse`（脈打ち・住民が正気に戻る）だけ起きて遊びに戻り、**光の穴**が開く。プレイヤーが穴のマスに入ると `rise` から今の昇階演出 | Kevin「自分で選んでる感」。シレン系は階段に自分で乗る。実利：住民が正気に戻った安全な階で、ハーケンを打ってから上がれる |
| 穴の位置＝**最後に灯した祭壇に隣接する通行可能マス**（祭壇マス `grid===2` は `isWall` で通れないため）。候補は上下左右の順で最初の床。無ければ最寄りの床（暫定） | 祭壇の上に置くと入れない（レビュー指摘）。`isWall` は触らない |
| 穴が開いている間、住民は正気のまま（知覚・接触・消灯・交戦・経路更新から外す）。祭壇は消されない | 「クリア済みの階」を壊さない。ハーケンを打つ余裕のため |
| **ハーケンの絵＝C**。渡す場面・HUD・床の3か所で同じ絵 | Kevin「Cかな」。類似作品の型：手に入れた瞬間に絵、以後同じ絵 |
| 渡す場面：`haken[1]`「これを、あなたに。ハーケンです。」の行で、**女神の手元（女神の少し前、画面中央）に絵が浮かび、クリックで HUD の位置へ飛んで本数になる**。飛行中は次の行を始めない | ゼルダ・ホロウナイトの「物が出る → 持ち物へ」。今は文字だけ。授与場面はベイビーを描かない（`drawGoddessVoid` L3001 `if(!scene.haken)`）ので**女神基準の配置**にする |

## 2. ハーケンの絵（C）

12×16 のドット。`docs/design/haken-mockup.html` の `PAL` と `SP.C.rows` をそのまま写す（縄 `r`/`R`、金属 `m`/`M`/`d`、穴 `k`）。火は縄の結び目（`fire:[8,3]`）の上に、今の `pin` の炎の描き方で。

```js
const HAKEN_PAL={k:'#1a1512',m:'#8e94a0',M:'#c9ced8',d:'#4a4f5a',r:'#8a5a34',R:'#b07a48'};
const HAKEN_ROWS=[
'....mmmm....','...mMkkMm...','...mk..km..r','...mMkkMmrR.','....mmmmR...','....dMMdr...',
'....dMmdR...','....dMmd.r..','....dMmd....','....dMmd....','....dMmd....','....dMmd....',
'.....dMd....','.....dm.....','.....dm.....','......d.....'];
function drawHaken(c,x,y,z){ /* c=描画先コンテキスト、左上 x,y、1ドット z px */ }
const HAKEN_ICON_URL = (一度だけオフスクリーン Canvas に z=2 で描いて toDataURL した PNG);
```

- **描画先を引数にする**（メイン `ctx` と HUD 用で共有）。通常 HUD は `log()` の `innerHTML`（L3288 付近）で約0.12秒ごとに再生成されるので、そこは `HAKEN_ICON_URL` の `<img>` を使う（毎回描かない）
- 床：1マス40px のとき z=2（24×32px、マスの中央下寄せ）。**L2387 の `mChip(TS*.24,2,true)` の呼び出しだけ**を `drawHaken(ctx,…)` に置き換える。炎・`glow`・脈はそのまま
- HUD（通常）：`⚑` を `<img src=HAKEN_ICON_URL>`（高さ約16px）に。**本数は `activeRun?activeRun.pinsLeft:P.pinCount`（今どおり）**
- HUD（暗闇の授与用 `drawHakenCount` L3015）：`'⚑×5'` 固定をやめ、絵＋`×`＋**同じ本数**に
- 渡す場面：z=6（72×96px）

## 3. 実装ステップ

### チャンク1：上る穴

#### Step 1: 最後に灯した祭壇を覚える
- `lastLitAltar={x,y}` を、直点火（L1309 `near.mine=true`）と種火点火（L1393 `m.sparkTarget.mine=true`）の**両方**で更新。`buildFloor()`（L1102）で `null`

#### Step 2: 最後の祭壇を灯したあと
- クリア判定 L1662 `if(mine()===altars.length)` の非進化・非最終階の分岐（L1677 `startAscent()`）を変える：`floorCleared=true` にして、**`pulse` 相当**（全祭壇の脈打ち・`freeFloorResidents()`・既存の2音）を `mode='won'`／`ascentAnim.phase='pulse'` で 0.6秒見せたら、`ascentAnim=null; mode='play'; setCinematic(false); invuln=Math.max(invuln,.8)` で遊びに戻す
- **`floorCleared` が真の間はクリア判定（L1662）を再実行しない**（毎フレーム再発火して `pulse` を繰り返すのを防ぐ）
- 穴：`exitHole={x,y,t}` を §1 の位置に置く。見た目：縦長の楕円の光（`rise` の穴と同じ絵）が床に開き、ゆっくり脈打つ。ミニマップにも印
- 帯（`drawBreathLesson` と同じ黒帯）に「**光の穴が開いた**」を1.4秒（**確定文言**）。女神の窓は使わない
- **初期化**：`buildFloor()`・土地開始（`prepareRunFromBeginning` L851 と `startTheme` 系）・ハーケン復帰の盤面準備、のすべてで `exitHole=null; floorCleared=false; lastLitAltar=null`。前の階の座標を持ち越さない
- 完了条件：最後の祭壇を灯す → 脈打ち → 遊びに戻り、祭壇の隣に穴。連続で脈打ちが繰り返されない

#### Step 3: 正気の住民を止める
- 現行の `e.freed` は `mode='won'` だから止まって見えるだけ。`mode='play'` に戻すと知覚（`enterEnemyChase` L691）・接触（`caught` L1678）・消灯（L1581〜 `e.douse`）・配下との交戦・経路更新が動く
- `e.freed` の住民を**次から除外**：知覚と追跡の開始、接触判定（`touchingMaster` と `caught`）、祭壇の消灯（`douse` を進めない）、配下との交戦（`adj`／攻撃）、経路の再計算。その場で小さく上下（今の `freed` の絵）だけ
- ミニマップ（`drawMinimap` 系）で `freed` の住民は**視野錐を描かない**（点だけ、暖色）
- 完了条件：穴が開いている間、住民は追わず、触れてもハートが減らず、祭壇が消されない。ハーケンを打てる、息止めも可

#### Step 4: 穴に入る
- ベイビーが `exitHole` のマスに着いた瞬間（`master.t>=1`）、`exitHole=null` にして **`startAscent('rise')`** で `rise` から始める（`startAscent` L1184 に**開始フェーズ引数**を足す。`'rise'` のときは `pulse` の初期化も**クリア時の2音も鳴らさない**）。以降は今どおり `floorCard` → `open`
- 節目の判定（`(floor+1)%10===0&&(floor+1)<FLOORS`）は今どおり `startAscent` の中で
- **最終階は穴を出さず `startFinalRelease` を今のまま自動**（土地クリアは儀式なので選ばせない。暫定）
- **進化階も穴を出さず `nextFloor()` 直行**（儀式が先。今どおり）
- 完了条件：穴に入ると浮上 → カード → 新しい階。穴に入らなければいつまでも上がらない。進化階・最終階は今どおり

#### Step 5: 開発導線「穴を出す」
- 現在階を「クリア扱い」にして穴を置く**見た目だけ**の経路。`freeFloorResidents()` の実処理は使わず、`e.freed=true` の見た目と `exitHole` だけを置く。**`activeRun.freedByFloor`・`campaign.freedTotal`・クリア登録・ラン保存は触らない**

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：ハーケンの絵

#### Step 6: 床と HUD
- §2 の `drawHaken` と `HAKEN_ICON_URL` を作る。床は L2387 の1か所だけ置き換え。通常 HUD（L3288 付近の `⚑×`）は `<img>`＋本数。暗闇 HUD（`drawHakenCount` L3015）は絵＋本数（5固定をやめる）
- 完了条件：打った床に縄つきハーケンが立ち、HUD に同じ絵と `×N`。開発パネルで本数を3にすると `×3`

#### Step 7: 渡す場面（取得フェーズを挟む）
- `advanceGoddess()`（L2931）の `talk` で `haken[1]` の行のクリック後、**`haken[2]` をすぐ始めない**。新フェーズ `hakenGet` を挟む：
  1. `haken[1]` の文字送りが始まった瞬間：女神の少し前（画面中央）に z=6 の絵が 0.3秒でふわっと現れる（下から少し浮く、`glow`）。今 `showCount` を立てている所はこのタイミングでは**立てない**
  2. 行の文字送りが終わってクリック → `hakenGet`：絵が 0.5秒で HUD の位置へ縮みながら飛ぶ。**飛行中はクリック・Enter を受け付けない**
  3. 着地：`showCount` を立てて絵＋本数が光って現れる（今のフェードをここに合わせる）→ `haken[2]` の文字送りを開始
- 取得済みの表示（絵＋本数）は、残りの会話（`haken[2]`・`[3]`）と `beginPinReturn` の復帰演出の間も**消さない**
- 完了条件：「これを、あなたに。ハーケンです。」で絵が浮かび、クリックで HUD へ飛んで本数になり、そのあと次の行が出る。飛行中に連打しても次の行が先に出ない

## 4. 便全体の完了条件
1. 最後の祭壇 → 脈打ち（1回だけ）→ 遊びに戻る → 祭壇の隣に穴 → 自分で入る → 浮上（2音なし）→ カード → 次の階。進化階と最終階は今どおり
2. 穴が開いている間に住民は追わず・触れず・消さず、ハーケンを打てる。ミニマップに視野錐が残らない
3. 床・HUD（通常・暗闇）・渡す場面の3か所が同じ縄つきハーケンの絵。本数は5固定でない
4. 渡す場面で絵が飛んでから次の行
5. 正典の詩は不変。`isWall`／`mChip` は不変
6. Sol がブラウザで 1〜4 を確認して HANDOFF に書く
