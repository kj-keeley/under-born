## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| **遺跡は16階**（`THEMES.ruins.floors=16`） | Kevin 確定 |
| **4区画×4階**：区画1＝1〜4F、区画2＝5〜8F、区画3＝9〜12F、区画4＝13〜16F | Spelunky の型。4階ごとに変わる＝Kevin の「3〜8階ごと」 |

| **区画ごとの住民**：区画1＝基本3種、区画2＝＋ランダム型、区画3＝＋鈍足型、区画4＝＋速殺型。数は区画1＝2体、区画2＝3体、区画3・4＝4体。**区画の最初の階は新顔を先頭に、以後の階は解禁済みの種類からまんべんなく**（§2 Step 3 の規則） | 4階ごとに新顔の自己紹介が1回来て、その後も出続ける（指摘1） |
| **区画ごとの色**：パレットを4段に | 変化が目で分かる |
| **休憩所**：4F・8F・12F の穴に入ったあと、5F・9F・13F に入る前に1つ。階数に数えない。住民なし、祭壇1つが灯っている、その区画で正気に戻した住民が火のまわりに座る、ハートが上限まで戻る、穴が最初から開いている | Hades の休憩部屋・Hollow Knight のベンチ・マザー2 のホテル。記録の列をここへ移す |

## 2. 実装ステップ

### チャンク1：16階・区画・地図・住民

#### Step 1: 階数と区画
- `THEMES.ruins.floors=16`。`zoneOf` は遺跡だけ `Math.min(3,Math.floor((f-1)/4))`（0〜3）。他の土地は今の3分割のまま（`THEMES[key].zoneOf` を持たせるか、関数に土地の分岐）
- `stageForFloor` は遺跡だけ `f>=13?3:f>=9?2:1`。他の土地は今の割合のまま
- `specialFloorAt('ruins',f)` は常に `null`
- **地図の選び方を1つの関数に**：`floorShapeFor(themeKey,f)` → 遺跡は区画で通常／`lFloor(0)`／`verticalFloor(0)`／`wideFloor(0)`、他の土地は今の `specialFloorAt` か通常。`buildFloor`（盤面生成）・`normalizeRun`（保存の座標検証、L408）・`prepareCheckpointBoard`（復帰の盤面、L831）の**3か所すべてがこれを使う**（指摘5）
- 完了条件：1F・5F・9F・13F で地図の形が変わる。断面図は16段

#### Step 2: 区画ごとの色
- `THEMES.ruins.palette` を4段に（区画4用を1つ足す。実装側判断）。`zoneOf` が0〜3を返しても他の土地の3段パレットが範囲外にならないよう、添字は `Math.min(zone, palette.length-1)`

#### Step 3: 区画ごとの住民（選出規則）
- 遺跡だけ `TYPE_MIX_RUINS=[['I','L','T'],['I','L','T','R'],['I','L','T','R','B'],['I','L','T','R','B','H']]`。数：区画1＝2、区画2＝3、区画3・4＝4（`baseEnemyCount` L1137 の遺跡分岐）。周回の＋1は今どおり
- 選出（L1143〜、遺跡だけ）：
  - 区画の最初の階（5F・9F・13F）：**新顔（その区画で解禁された種類）を先頭**、残りは解禁済みから順に
  - それ以外の階：**開始位置を階ごとにずらす**（`mix[(i+floor)%mix.length]`）。これで 6〜8F でも R が、10〜12F でも B が、14〜16F でも H が出る（指摘1）
  - 1〜2F は今の「基本3種のみ」と同じ
- 完了条件：5F で初めてランダム型の自己紹介、9F で鈍足型、13F で速殺型。6F・7F・8F のいずれかでランダム型が再登場

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：休憩所

#### Step 4: 休憩所の状態（`mode='play'` のまま、`restRoom` フラグで区別）
- **新しい `mode` は作らない**（`stepBy` L3506・`beginPinHold`・`updatePinHold`・メインループ・穴の進入判定・ポーズ復帰がすべて `play` 限定のため。指摘2）。代わりに **`restRoom=true`** を持ち、`play` の中で「休憩所では動かないもの」を止める：住民の生成と更新、祭壇の点火判定（`floorCleared=true`）、息止め、タイマー（`stats.t` は進めない）、敵紹介
- **実行時の階番号と姿**（指摘7）：休憩所中は `floor` を**直前にクリアした階のまま**（4・8・12）にし、`restRoom=true` と `restNext=floor+1` を持つ。`masterStage()` は儀式前の姿のまま（`stageForFloor(4|8|12)` なので自動）。**退出時に一度だけ** `startAscent('rise')` → カード「遺跡 5F」→ `prepareAscentFloor` で `floor++`（9F・13F に入るときは Step 6 の儀式）
- 盤面：`makeRestMap()`（8×8 程度の一部屋、実装側判断）。中央に祭壇1つ（`mine=true`）、その周りにその区画で正気に戻した住民（`activeRun.freedByFloor` の直前4階ぶん）が座って小さく上下（`freed` の絵、当たり判定なし）、部屋の端に `exitHole`
- 入った瞬間：`hearts=maxHearts`、帯に「ここは、しずかだ」（**暫定文言**。システムの声）
- 完了条件：4F の穴 → カード「遺跡 休憩所」→ 静かな部屋、住民が火のまわり、ハート満タン、移動できる、住民は出ない → 穴 → カード「遺跡 5F」→ 5F

#### Step 5: 休憩所のハーケン（指摘3・4・5・6）
- 入った瞬間に**自動で** `pinAtMaster(true)`（演出なし・消費なし）。`activeRun.pin={floor:<クリアした階>,rest:true,x,y,hearts}` として保存。**未授与（`campaign.hakenGiven` 偽）でも自動設置は動く**が、床・ミニマップ・HUD には出さない（7h の条件を維持）。授与済みなら休憩所で手動で打つのも今どおり（4秒・演出あり・消費なし）
- **復帰**：ハート0で `pin.rest` が真なら休憩所へ戻る（`prepareCheckpointBoard` が `floorShapeFor` ではなく `makeRestMap()` を組み、`restRoom=true; restNext=pin.floor+1`）。復帰時の1本消費は今どおり
- **保存と読み込み**：`normalizeRun` が `pin.rest` を真偽で正規化し、`rest` のときは休憩所の座標で検証。「つづきから」で休憩所に戻れる。通常階で新しく打ったら `rest=false`
- **表示先の区別**（指摘6）：床・ミニマップの杭の描画条件を `pin.floor===floor && !!pin.rest===restRoom` にする（休憩所の杭が 5F に出ない、4F の杭が休憩所に出ない）
- 完了条件：休憩所で保存 → 再読み込み → 「つづきから」で休憩所。休憩所を出て 5F でハート0 → 休憩所に戻る（本数1減）。未授与の新規開始で休憩所に杭が見えない

#### Step 6: 進化の入口（指摘8）
- 現行の全灯分岐（L1701 付近）は `stageForFloor(floor+1)>stageForFloor(floor)` なら `nextFloor()` 直行。**遺跡ではこの分岐を使わない**：全灯 → 穴（今どおり）→ 穴に入る → 4F・8F・12F なら休憩所へ、それ以外は `rise` → カード → 次の階
- 儀式は**休憩所の退出時**：8F の休憩所の穴に入る → `startEvolution(1,2)` → 暗闇の声（`child`）→ 女神 → 光で 9F。12F の休憩所も同じ（`lord`、13F）。順番は「休憩所 → 儀式 → 新しい階」で、昇階カードは出さない（儀式の光で階が見えるのが今の型）
- 他の土地の分岐（割合計算・`nextFloor()` 直行）は維持
- 完了条件：9F と 13F に入るとき儀式と詩。16F は儀式なし。8F・12F の全灯で儀式が先に来ない

#### Step 7: 節目カードの廃止と開発導線（指摘10）
- `milestone` は遺跡で常に偽（他の土地は維持）
- 開発パネル：「指定階へ移動」は16階まで。「休憩所を試す」は**見た目だけ**：`activeRun`・`campaign.freedByFloor`・`freedTotal`・クリア登録・ラン保存を変更せず（自動ハーケンも打たない）、盤面と住民の座りだけを組む。「住民の列を試す」は休憩所の絵で
