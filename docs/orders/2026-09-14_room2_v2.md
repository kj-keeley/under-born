## 1. 決定と形

| 決定 | 形 |
| --- | --- |
| 浄化の時間割（指摘1・2） | **0〜1.5秒＝待機**（暗い地上のまま。**既存の `grow` の緑と光の広がりもここでは進めない**）→ **1.5〜4.0秒＝浄化**（`purify` 0→1。色・緑・光・木・空がここで進む）→ **4.0〜7.0秒＝歩行**（ベイビーが歩き、住民が順に現れる。今の「0秒から歩いて3秒で詩」を4秒ずらす）→ **7.0秒＝土地の詩** |
| 空 | `campaign.room.picture`：`sun`＝夜明けから日の出（空の色が紫→橙→薄い青、太陽が地平線から上がる）／`moon`＝月夜（濃い青、月）／`stars`＝星空（濃紺、星の点が瞬く）／`null`＝今の暗い空のまま（浄化は地面と木だけ） |
| 鳥 | `room.owned.bird` なら空に小さな鳥が3〜5羽、右へゆっくり飛ぶ（絵が `null` でも飛ぶ） |
| 木 | `room.trees` の段（0〜4）どおりに、地面に木を5本（左から）。段0は何も無し。段4は花。休憩所の鉢の絵と同じ描き方を大きくして使う |
| 「旅の果て」 | 背景は `drawEndingBackdrop`（毎フレーム黒で塗る関数。`showEnding` ではない。指摘5）を、浄化後の空の色に。断面図と数字3つはそのまま。**周回ダイヤルも同じ背景** |
| 適用範囲（指摘4） | **遺跡（`finalLand` かつ `curTheme==='ruins'`）だけ**。開発用の他4土地の地上景は今の色・時間のまま |
| 描画用の時間（指摘3） | `surfaceAnim.t` は詩の間に止まり変身で0に戻り、住民列は固定値で描くので、**`purify` は1に達したら保持**し、鳥と星の動きは `performance.now()` ベースの別時計（`surfaceAnim.skyClock`）で描く。詩→変身→列→旅の果てまで浄化後の絵が続く |
| 周回 | 2周目以降も部屋は残るので、2周目のエンディングは1周目より育った地上になる |

## 2. 実装ステップ

### チャンク1：空と木
#### Step 1: 浄化の進み
- `surfaceAnim.purify`（0→1）を `grow` の 1.5〜4.0秒で進め、**1 に達したら保持**。`drawSurfaceWorld` の空・地面の色を `THEMES.ruins.surface` から「部屋の見た目」へ `purify` で補間。**既存の緑と光の広がり（`grow` の 0.4秒〜）も `purify` に従わせる**（待機中は進まない）
- 歩き出し（`walking`）は 4.0秒から、住民の登場時刻も歩き出しに合わせる。土地の詩（`growAt`）は 7.0秒
- 遺跡以外（開発用）はこの処理を通らない
- 完了条件：地上に出て1.5秒は暗いまま（緑も光も広がらない）、1.5〜4秒で明るくなり木が伸び、4秒から歩く

#### Step 2: 空
- `picture` ごとに空を描く関数 `drawPurifiedSky(purify,t)`：sun＝地平線から太陽（`purify` で上がる）、moon＝月、stars＝星の点（`t` で瞬き）、null＝今の空
- 鳥：`owned.bird` なら小さな鳥（V字2画）を3〜5羽、`skyClock` で右へ。星の瞬きも `skyClock`
- 完了条件：太陽の絵を飾っていれば日の出、月なら月夜、星空なら星、無しなら今の空。鳥があれば飛ぶ

#### Step 3: 木
- 地面に鉢と同じ位置関係で木を5本（`W*.15,.30,.45,.60,.75` 付近、暫定）。段に応じて休憩所の絵（L2594 付近）を `W*.06` 程度に拡大。`purify` で下から伸びる
- 完了条件：休憩所で育てた段どおりの木が地上に生える

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：旅の果てと開発導線
#### Step 4: 旅の果て
- `drawEndingBackdrop` の背景を浄化後の空の色に（`picture` 無しなら今の黒）。数字3つと断面図は今どおり。周回ダイヤル（同じ背景）も同じ
#### Step 5: 小直し（部屋便①の文言）
- 所有済みの鳥（`もっている`）を選んで Enter したとき、今は「ひのつぶが たりないみたい。」が出る。**選べない品を選んだときは何も言わない**（音だけ小さく）に統一

#### Step 6: 開発導線
- 「地上演出を試す」で、今の `campaign.room` を使う。プレビュー用に「部屋を満開にして試す」：**`roomOverride={trees:[4,4,4,4,4],owned:{sun:true,moon:true,stars:true,bird:true},picture:'sun'}`** を一時的に持ち（本番と同じ形。指摘6）、地上から「旅の果て」まで同じ一時データで描き、周回ダイヤルを閉じるかタイトルへ戻ったら解除。`campaign.room` は書き換えない
