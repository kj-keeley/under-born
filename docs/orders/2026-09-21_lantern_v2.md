## 1. 決定
| 項目 | 内容 |
| --- | --- |
| どこに出るか（暫定） | **遺跡 9F〜16F（区画3・4）の祭壇は全部「吊り灯籠」**。1〜8F は全部石皿（**必要数は既存の `tapNeed()` に従う**＝段階1で3、段階2・3で2、真の姿1、暗火は切り上げ半分。指摘6）。祭壇に `kind:'dish'|'lantern'` を持たせ、生成（L1391）で **`curTheme==='ruins'&&zoneOf(floor)>=2`** なら `lantern`（指摘1。開発用の他4土地は石皿のまま）。開発パネルの「全部／なし」は別の上書き変数 `devLanternMode` で、`buildFloor` 時にこの判定より優先する。逃げる祭壇（5F〜の最遠1基）が 9F〜なら灯籠のまま逃げる（揺れは止まっている間だけ） |
| 揺れ始め | 隣に立ち止まって（今の `tapInputReady` の条件）**最初の1打**で灯籠が揺れ始める（判定なし、「カチ」の音だけ）。周期 **1.0秒**（`P.lanternPeriod`）、振れ幅は左右に約0.55ラジアン相当（描画）。0.3秒で振れ幅が立ち上がる |
| 当たり | 揺れ始めた後の打で、**灯籠が真ん中（吊り元の真下）を通る瞬間の前後 ±0.12秒**（`P.lanternWindow`）なら当たり → **その1打で点く**（必要数は段階に関係なく1。暗火も1）。今の `igniteAltar` を呼ぶ |
| 外れ | 窓の外で叩く → 鈍い音（`tone(180,.08,'square',.05)`）と灰色の粒2〜3。**減るものは無い**。揺れはそのまま続く。何度でも |
| 空振り | 前の打から 0.22秒未満は数えない（石皿と同じ `P.lighterMin`） |
| 止まる | 3秒（`P.lanternIdle`）叩かないと振れ幅が 0.8秒で0へ戻り、次の打でまた揺れ始めから。離れる・対象が変わる・捕獲・通常コアの息止め・祭壇が動き出す・`buildFloor` で `resetTap()`（振れも0） |
| 保留（指摘2・3） | **灯籠は連鎖ポーズ中も送り先選択中も入力を受けない**（石皿の「連鎖中は叩ける」はそのまま）。保留中は揺れの時計を止め、位相・振れ幅・放置時間をそのまま保持し、明けたら同じ位相から再開する。揺れている状態は消さない（`resetTap` しない） |
| 時計（指摘2） | **灯籠専用の時計 `swingT`**：`mode==='play'` かつ保留でない間だけ `rawDt` を足す（`tapClock` は保留中も進むので使わない）。位相 `phase=swingT/P.lanternPeriod`（揺れ始めで `swingT=0`）、位置 `sin(2π·phase)`、真ん中＝`sin` が0を横切る瞬間（周期ごとに2回）。判定は「最も近い0交差までの `swingT` 上の時間 ≤ window」。**描画・判定・放置時間・振れ幅の立ち上がりと減衰はすべて `swingT` を参照**（保留中は全部止まる）。空振りの 0.22 秒も `swingT` で測る |
| 進捗とカメラ（指摘4） | 灯籠の「操作中」＝揺れている（`swingAmp>0` または始動打から放置時間内）。8p の `keepIgnitionView`／`tapFocus` の条件（`tapHits>0` または `tapFx` が生きている）に **灯籠の操作中を加える**：連鎖ズームを通常倍率へ戻し、配下より灯籠を映し続ける（始動打は成功数に数えないので `tapHits` は0のまま） |
| 見せ方 | 吊り元（マスの上端の小さな金具）から鎖、先に灯籠本体（仮のコード描き。四角い箱に小さな窓）。揺れは鎖の先端の横位置 `sin` で描く。**合図＝真ん中に近いほど灯籠の中の燠が明るむ**＋吊り元から床へ薄い点線（揺れている間だけ）。当たり＝燠が炎になり、**揺れが 0.8秒で収まる（指摘5：収まる演出は祭壇ごとの `a.settleT`／`a.settleFrom` に持たせ、`resetTap()` で消えない。開始は `igniteAltar()` の末尾と、配下の点火経路（`igniteAltar` を通らない側）の両方）**、火花の粒、石皿と同じ「部屋が膨らむ」（`tapFx.pulse=1`）。配下が揺れていない灯籠を灯した場合は収まる演出なしで炎だけ。外れ＝灰色の粒＋`tapFx.sink=1`。未点火の灯籠も暗闇・壁越しに弱い赤で見える（石皿と同じ目印の役目）。点火後は暖色の炎で、揺れない |
| ミニマップ | 灯籠は小さな「吊り」印（仮）。色は石皿と同じ規則（未点火＝暗い赤茶、点火＝暖色） |
| 音 | 揺れ始め「カチ」（石皿の当たりと同じ2音）。当たり＝`sfxIgnite()`（今どおり）。外れ＝上の鈍い音。真ん中を通る瞬間ごとの合図音は**入れない**（音なしで分かる設計。うるさい） |
| 状態の文 | 灯籠の隣：揺れる前「火を 打つ」、揺れている間「**真ん中で 打つ**」（暫定） |
| `wait` モード（指摘6） | 灯籠も今の待ち点火（**既存の `igniteNeed()` に従う**＝段階1で1.4秒、段階2・3で短く、真の姿は即時、暗火は半分）。振り子なし |
| 開発パネル | 「灯籠：9F〜／全部／なし」（生成に反映、`buildFloor` し直し）、「灯籠の周期 0.6〜2.0」「当たり幅 0.05〜0.3」「止まるまで 1〜6秒」 |

## 2. 実装ステップ
### チャンク1：生成・判定
- `kind` の付与、`registerTap` を `tapTarget.kind==='lantern'` で分岐（揺れ始め／当たり／外れ）、`updateTapIgnition` に揺れの状態（`swingStartT`・`swingAmp`・最終打刻）と止まる処理、保留の扱い
- 完了条件：9F で灯籠の隣に立ち1打で揺れ始め、真ん中で叩くと点く。端で叩くと外れで減らない。3秒放置で止まり次の打で再開。1F の石皿（通常コア・段階1）は 8p のまま3打。**連鎖ポーズ中は灯籠を叩けず、位相・振れ幅が止まり、明けると同じ位相から続く。灯籠を揺らしている間に配下が別の祭壇を灯してもカメラが灯籠を映し続ける**
**ここでチャンク1完了報告。**

## 3. 完了条件（便全体）
1. 新規開始→（開発パネルで 9F へ）灯籠が説明なしで分かる（Sol の感触1行）。1F の石皿は 8p のまま
2. 逃げる灯籠（9F〜）：動いている間は揺れず叩けない。止まると揺らせる
3. 種火配下は灯籠も操作なしで灯す。`sparkSelect` は今どおり
4. `wait` で灯籠も既存の待ち点火に戻る（通常コア・段階1で1.4秒、真の姿は即時）
4b. 自己点火・配下点火のどちらでも、揺れていた灯籠は 0.8秒で収まって炎になる（`resetTap` 後も演出が残る）
5. 390px 幅で短いタップが揺れ始め・当たりになり、ドラッグで離れられる
6. 正典の詩は不変
