## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| **敵は人間ではなく「目的を失ったダンジョンの住民」**。語を「侵入者」→「住民」に（画面の文字列・GAME_DESIGN・ENEMY_INFO の説明文）。祭壇をすべて灯した階の住民は**正気を取り戻す**（追うのをやめ、色が冷たい青から暖かい色へ、ベイビーに手を振る） | Kevin の言葉。類似：Undertale（見逃した相手は最後に並ぶ）、マザー2（敵を正気に戻す） |
| **初登場の自己紹介**：既存の敵紹介ズーム（`enemyIntro`）の間に、画面下の窓（女神便の `drawTextWindow` と同じ）で一言。**住民の声＝女神の詩とは別の声**（明るくてよい） | Kevin：「おれはランダムに歩き回るやつだぞー！とか自己紹介ぽいなにか」。マザー2の敵の名前と一言の温度 |
| **階を上がる演出**（進化の階を除く全階）：最後の祭壇を灯す → 全祭壇が脈打ち光が広がる → その階の住民が正気に戻る → 頭上に光の穴 → ベイビーが上へ浮かんで消える → 黒い一拍に「遺跡 3F」と小さな断面図（印が一段上がる）＋上がる2音 → 新しい階。**普段は合計2秒台、クリックで飛ばせる** | トルネコ・シレンの「黒 → 階数の文字 → 新しい階」。213回起きるので短く |
| **節目の階（10・20・30・40）**は黒い一拍が少し長く（3秒）、**ここまで正気に戻した住民がベイビーの後ろに並ぶ**（数が増えていく） | マザー2の写真屋の代わり＝「その瞬間は小さく、最後に全部が見える」。Kevin：「記録は正気に戻した住民が並ぶ」で確定 |
| **地上とエンディング**：正気に戻した住民たち（ユニークな住民も）が並んで喜ぶ。地上は土地ぶん、森のエンディングは5土地ぶん | Kevin：「最後はユニークエネミーも並んで喜んだり」。Undertale の平和ルート、カービィ／塊魂のエンディングの並び |
| 記録の数は**土地ごと**（地上で並ぶ）と**通算**（エンディングで並ぶ）の2つを保存 | 地上は「この土地の住民」、エンディングは「旅で会った全員」 |

## 3. 実装ステップ

### チャンク1：住民

#### Step 1: 語の置き換えと自己紹介
- 画面の文字列「侵入者」→「住民」（L3136 ほか。`grep 侵入者` で全部）。GAME_DESIGN の世界観の文（L23・L34）は §8 で更新
- 敵紹介ズームの間（`enemyIntro`、`dur:3.8`）、フォーカスが最大の区間（`introProgress` 0.18〜0.72）に画面下の窓で `ENEMY_INFO[type].intro` を文字送り。クリックで飛ばす（既存の `skipEnemyIntro` の前に窓を閉じる）。**ズームの秒数は変えない**
- 完了条件：初めて各種類に会ったとき、ズーム中に窓で一言が出る。2回目以降は出ない（既存の `seenEnemyIntros` どおり）

#### Step 2: 正気に戻る（階クリア時）
- 最後の祭壇を灯した瞬間（L1598 の `mode='won'` に入る所）、その階の `enemies` すべてを `e.freed=true` にする：追跡・捜索・巡回を止めてその場で立つ、色を `ENEMY_INFO.color` から**暖色**（`255,196,107` に 0.6秒で寄せる）へ、頭上に「♪」を1.2秒、ベイビーの方を向いて小さく上下（手を振る代わり。絵は変えない）
- 数える：`run.freed[type]++`（土地ごと）、`campaign.freedTotal[type]++`（通算、保存）。**同じ階で複数いれば全部数える**。ユニーク（特殊敵）も同じ
- 完了条件：階クリアの瞬間に敵が止まって暖色になり「♪」。次の階では今どおり冷たい住民

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：階を上がる

#### Step 3: 昇階演出（`mode='won'` の 0.8秒を作り直す）
フェーズ（合計 約2.4秒、進化の階は今どおり儀式へ）：

| フェーズ | 見えるもの | 秒 |
| --- | --- | --- |
| `pulse` | 全祭壇の火が一度いっせいに脈打ち、ベイビーの光が種火連鎖と同じ絵で広がる。住民が正気に戻る（Step 2）。既存の2音（L1599）はそのまま | 0.6 |
| `rise` | ベイビーの頭上に光の穴（縦長の楕円、`glow` の系統）が開き、ベイビーが上へ浮かんで穴に吸われて消える（`renderMasterBody` を y 方向に動かすだけ） | 0.6 |
| `floorCard` | 真っ暗。中央に「**遺跡 3F**」（土地名＋次の階）。その下に**小さな断面図**（`drawCrossSection` L3221 を縮小して使う）でベイビーの印が一段上がる。上がる2音（`tone(659,.08,'triangle',.06)`→`tone(988,.25,'triangle',.07,.08)`） | 0.8 |
| `open` | 新しい階が暗闇からベイビーの光だけで見えてくる（今どおり `nextFloor` → `buildFloor`） | 0.4 |

- **クリック／Enter で `floorCard` を飛ばせる**（`pulse`・`rise` は飛ばせない）
- `markAt(…'階へ')`（L1600）は消す（`floorCard` に置き換わる）
- 完了条件：階クリア → 脈打ち → 浮上 → 黒に「遺跡 3F」と断面図 → 新しい階。合計2秒台。連打すると `floorCard` が飛ぶ

#### Step 4: 節目の階（10・20・30・40。土地ごとに `floor%10===0`、最上階は除く）
- `floorCard` を 3.0秒にし、「遺跡 10F」の下に**ここまで正気に戻した住民がベイビーの後ろに並ぶ**（`run.freed` の数だけ、種類ごとに既存の敵の絵を暖色で小さく横一列。多ければ2列、上限は画面幅で切って「…」）。並んだ住民が小さく上下する。音は同じ2音＋余韻1つ
- クリックで飛ばせる
- 完了条件：10F クリアで住民の列が出て、20F で増えている

### チャンク3：地上とエンディング

#### Step 5: 地上で並ぶ
- `drawSurfaceWorld`（地上）で、土地の詩の窓が閉じたあと（遺跡は `grow` 完了後）、**地面にその土地で正気に戻した住民が横一列に並び**、ベイビーの方を向いて小さく跳ねる。女神の場面（森）とは重ねない（女神が出る間は住民は静止）。数は `run.freed`
- 完了条件：地上で住民の列が見える。0人なら何も出ない

#### Step 6: エンディングで並ぶ
- `showEnding`（L3089）の前に、森の地上で **5土地ぶんの住民（`campaign.freedTotal`）が並んで喜ぶ**場面を 3秒（変身のあと、光が広がった状態で）。ユニークな住民も同じ列。クリックで飛ばせる
- 「旅の果て」の仮の文はそのまま（エンディングの詩は未執筆）
- 完了条件：森クリアで住民の列 → 「旅の果て」

#### Step 7: 保存と初期化
- `run.freed`（土地ごと、`RUN_KEY` に含める）、`campaign.freedTotal`（`defaultCampaign`／`normalizeCampaign` に追加、保存）。「進行をリセット」で両方ゼロ
- 開発パネル：「住民の列を試す」（`run.freed` に仮の数を入れて `floorCard` を出す）
