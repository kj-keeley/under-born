## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| **吹き出しは女神の体に一切かぶせない。** 頭の上に隙間を空けて置く。上に入らなければ横（左右の空いている側）、それも無理なら画面の上端の帯 | 他のゲームの作法：ペーパーマリオ・Undertale・ゼルダ夢島の吹き出しは頭の上か横で、顔にはかからない。マザー2・ポケモンは画面の下（上）の窓で、キャラに重ねない。「顔にかぶる」のはどちらの型にも無い |
| **登場に「間」を作る。** 光が集まる → 女神が現れる → 一拍 → 吹き出し | 「突然出てくる」への答え。何かが起きる予告があれば、プレイヤーは「誰か来る」と分かる |
| **クリックは「消す」ではなく「次へ進む」。** 1回目のクリックで次の行（または吹き出しを閉じる）、吹き出しが閉じてから女神が光になって消える | 「クリックしたら即消える」への答え。マザー2・ポケモンは「クリック＝次の文」。消えるのは話が終わってから |
| **吹き出しに「▼」の点滅**（続きがあるとき）と、最後の行では「▼」を出さない | 「まだ続く／もう終わり」が分かる、全ゲーム共通の記号 |
| 正典の詩が2行あるときは**1行ずつ**出す（改行はそのまま。1行目 → クリック → 2行目） | 短い窓で読める。本文には触らない |

## 2. 実装ステップ

### Step 1: 吹き出しの位置（`drawSpeechBubble`）
- 女神の**矩形**（`renderGoddess` の描画範囲：足元中心から幅 `20*dot`、高さ `27*dot`、光輪ぶん上に `+3*dot`）を受け取り、吹き出し（しっぽ含む）がこの矩形と**重ならない**ことを保証する
- 置き方の順：①頭の上（窓の下辺が光輪の上 `4*dot` 以上）→ ②左右（女神の横 `4*dot` 空けて、画面内に収まる側。しっぽは横向きに口へ）→ ③画面上端の帯（`CS*.03` から。しっぽは口へ長く伸ばす）
- しっぽは今のまま口へ。ただし**しっぽが顔を横切らない**（顔の矩形＝上から 4〜10 行目の範囲を避ける。横に出すときはしっぽの先を口の横端に）
- 完了条件：開発パネル「女神を試す」を10回押して、どの出現位置でも吹き出しが女神にかぶらないこと（画面の四隅近くに女神が出た場合を含む）

### Step 2: 登場の間（`beginGoddess`／`updateGoddess`／`drawGoddessScene`）
- フェーズを変える：`in`（0.5秒）→ **`arrive`（0.8秒）** → `talk` → **`leave`（0.9秒）**
  - `in`：女神が立つ床に光が集まる（半径 `1.2*TS` の柔らかい光が 0 → 1）。女神はまだ描かない
  - `arrive`：女神が光の中から 0→1 でフェードイン。上下の揺れとウェーブは動いている。**吹き出しは出さない**
  - `talk`：吹き出しを出す（下記）
  - `leave`：吹き出しは消えている。女神が光に溶ける（alpha 1→0、足元の光が 1→0）。そのあと `mode='play'`
- 効果音（`audioReady` のとき）：`in` の始まりに `tone(523,0.4,'sine',0.05)` と `tone(659,0.5,'sine',0.05,0.25)` の2音（上がる）。`leave` の始まりに逆順の2音。既存の `tone` を使う
- 完了条件：光が先に集まり、女神が現れ、一拍おいて吹き出しが出ること。消えるときは吹き出しが先に消え、女神が光に溶けること

### Step 3: クリック＝次へ（`skipGoddess` を置き換え）
- `talk` の中に `lineIdx` を持つ。吹き出しには `lines[lineIdx]` の**1行だけ**を出す
- タップ／クリック／Enter／スペース：`lineIdx+1 < lines.length` なら次の行へ（吹き出しはそのまま、文字だけ切り替え）。最後の行なら吹き出しを閉じて `leave` へ
- 自動送りは残す（各行 3.6秒。触らなくても進む）。**`in`／`arrive`／`leave` の間はクリックを受け付けない**
- 「▼」：続きがある行のとき、吹き出しの右下に `▼` を 0.6秒周期で点滅。最後の行では出さない
- 完了条件：開始詩（2行）で、1回目のクリックで2行目に切り替わり、2回目のクリックで吹き出しが閉じて女神が消えること。クリックしなければ自動で同じ順に進むこと

### Step 4: 森の地上（`drawSurfaceWorld`）
- 地上の女神も Step 1 の「かぶらない」規則を適用（女神は左 `W*.16`、吹き出しは頭の上）
- 解放詩（2行）は1行ずつ。ただし地上は自動送りのみ（クリックは今のまま受け付けない。既存のタイムラインを守る）。行の切り替えは `releaseA` の区間を2等分
