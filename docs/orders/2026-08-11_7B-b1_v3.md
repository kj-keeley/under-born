### この便の役割
息を止めている間の手触りを変える。目指しているのは、**大人から隠れながら火をつけて回る子どものくすくす**という体験であり、現在の「見つかったら減る」一方向の緊張ではない。

あわせて、Kevinが息止めの秒数と光の半径を自分で探れるようにする。

### 壊すな指定
- 光と息止めの**ロジックの構造**（視界・晒し半径の二重構造、点火可否の判定、段階倍率の掛かり方）
- 種火連鎖、敵AI、マップ生成
- 7A・7A-hotfix・7B-aで実装した内容
- **敵側の定数と発見の計算式は変更しない。** 気づく半径、松明が照らす半径、前方視野、見回す時間、巡回・追跡速度、判定のロジックはそのまま
- ただし、**Step 5 で指定する光半径の変更にともなって発見される距離が実際に変わることは、意図した結果として許可する。** 光が小さくなれば見つかりにくくなるのは当然であり、この便の目的の一部
- **`P` の値のうち、この指示書が名指しで変更を指示したもの以外は変更しない**

**`renderMasterBody` は今回に限り変更対象とする。** これまでの便では壊すな指定に入れていたが、この便の主題そのものであるため解除する。

## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| 息止め中、マスターの体を透明にし、**瞬く目だけを残す** | 布団に隠れて目だけ出している状態に近い。隠れながら見ているという主体性が生まれる |
| 現在の「目を閉じて縮こまる」表現をやめる | 現在は `hold` 時に瞬きが `0.05`（ほぼ閉眼）、殻が `cold`、震えが入り、**受け身の縮こまり**になっている。かくれんぼの主体が自分側に来ない |
| **目は敵からは見えない。** 発見条件を一切変えない | まず演出として入れる。難易度が変わると、光と目のどちらが原因か切り分けられなくなる |
| 息止め中の目は、**通常本体と同じ瞬き**にする（`mBlink(3.4, 0)`） | 通常時と隠れている時で同じ目であること。卵・ロゴ側の `ubBlink`（4.6秒周期）との統一は孵化演出（7B-b）で扱う |
| 息止めの秒数をデバッグスライダーで調整可能にする | `BREATH_MAX`（L364）が定数で `SPEC` に入っておらず、現状では試せない |
| 光の半径の初期値を最小近くに下げる | 実プレイで「大きすぎてすぐ気づかれる」との判断。小さいほど「照らす範囲」ではなく「自分の体」に近づく |
| 光の**描き方**（グラデーション、境界のぼかし）は変更しない | 境界が曖昧であることが「どこまで見えているか分からないから多めに隠れる」という緊張を作っている。また祭壇・松明・種火が同じ描き方で揃っており、マスターだけ変えると浮く |

## 2. 棄却した案

**再提案しないこと。**

| 案 | 棄却理由 |
| --- | --- |
| 息止め中の目を敵に見えるようにする（至近距離で気づかれる） | まず見えない側で入れる。甘いと感じたら次便で検討する |
| 光の描き方そのものを作り直す（境界をはっきりさせる等） | 曖昧さが緊張を作っている。他の光源とも揃っている |
| 息止め中も体を薄く残す | 目だけにする。中途半端に残すと「消えている」感が出ない |
| 息を吐くときに光の半径をオーバーシュートさせる | `master.r` は敵に発見される距離の計算に使われる。演出のために発見判定を変えることになる |
| 本体の瞬きを卵・ロゴの `ubBlink`（4.6秒周期）へ統一する | 別実装であり、この便では移植しない。卵との統一は孵化演出（7B-b）で扱う |

## 3. 実装ステップ

### チャンク1（生存確認用・小）

#### Step 1: 息止めの秒数をスライダーに出す
- **`SPEC`（L2709-）は `P[k]` を参照する仕組みであり、`const` をそのまま追加しても動かない。** 次の移設が必要
  - `const BREATH_MAX=3.0`（L364）→ **`P.breathMax`**
  - `const BREATH_CD=5.0`（L365）→ **`P.breathCd`**
- あわせて参照箇所を書き換えること
  - `breathMax()`（L371）— 段階倍率を掛けている関数。**倍率の構造（段階2で1.3倍、段階3以上で1.5倍）は変えず**、基準値だけ `P.breathMax` を見るようにする
  - `releaseBreath()`（L2547付近）— `breathCooldown=BREATH_CD` を `P.breathCd` に
  - 説明文（L2767付近）— `${BREATH_MAX}` `${BREATH_CD}` の埋め込みが、スライダーで変えた現在値を反映するようにする。テンプレートが起動時に一度だけ組まれている場合は、パネルの値変更時に組み直すか、表記から具体値を外すこと
  - その他 `BREATH_MAX` / `BREATH_CD` を参照している箇所すべて
- `SPEC` に追加するグループは「操作」が自然。**スライダーの範囲は次のとおり**
  - `breathMax`: 最小 **1.0**、最大 **12.0**、刻み 0.5
  - `breathCd`: 最小 **0.5**、最大 **15.0**、刻み 0.5
- 完了条件：パネルで息止めの基準値を **6.0** にしたとき、段階1で**6秒**、段階2で**7.8秒**、段階3および真の姿で**9秒**息を止められること。クールタイムのスライダーも実際の待ち時間に反映されること。**ポーズを挟んでも値が元に戻らないこと**

**ここでチャンク1完了報告を出すこと。以降は報告後そのまま続行し、Kevinの返事を待たない。**

### チャンク2：息止め中の見た目

#### Step 2: 体を透明にし、目だけ残す
- `renderMasterBody`（L1364）の `hold` が真のとき、**体（殻・亀裂・火の点・殻片・影）を描画しない**
- **瞬く目だけを描く。** 段階2・3で使われている `mEye` を流用してよい
- 段階1（ベイビー）は現在 `mEye` を使わず火の点だけを描いている。**息止め中は段階1でも目を描くこと。** 卵の中の目・割れて出た目・隠れている時の目が同じものであるという設計に基づく
- 目の色・大きさは実装側判断でよいが、**通常時よりわずかに暗く**すること（光っていないため）
- **体に付随するものをすべて描画対象から外すこと。** 殻・亀裂・火の点・殻片・影に加えて、以下も残さない
  - **コア固有の装飾**（転位・暗火・霞などコアごとの見た目の差分）
  - **金フラッシュ**などの一時的なエフェクト
  - **真の姿（段階4）の衛星破片**
- **`renderMasterBody` を変えるだけでは「目だけ」にならない。** 暗闇レイヤーの描画で、マスター由来の以下2つが無条件に実行されている
  - L1756 `cut(..., S(master.r+0.6), 0.3)` — 暗闇を抜く
  - L1764 `glow(..., S(master.r*0.95+0.8), ...)` — 暖色の残光
  - `P.r0` を 0 にしても定数項（`+0.6` / `+0.8`）が残るため、光が完全には消えない
- **息止め中（`glowing()===false` のとき）は、この2つのマスター由来の描画を行わないこと。** 祭壇（L1754, L1761）と敵（L1755, L1763）の `cut` / `glow` はそのまま残す
- **`cut()` と `glow()` の関数そのもの（グラデーションの描き方）は変更しない**
- 完了条件：息を止めるとマスターの体が見えなくなり、瞬く目だけがその場に残ること。**段階1・2・3・4のすべてで、かつ全コア（初期・転位・暗火・霞）で**同じであること

#### Step 3: 縮こまりの表現をやめる
- `hold` 時の以下を削除または見直す
  - 瞬き `blink=hold?0.05:...`（L1382）— **ほぼ閉眼になっている。通常と同じ周期で瞬くこと**
    - **瞬きの実装は本体側の `mBlink(3.4, 0)`（L1358）に統一する。** 卵・ロゴ側の `ubBlink(t, 4.6)`（L2048）は別実装であり、周期も異なるが、**今回は移植しない**。本体の見た目の一貫性を優先し、卵との統一は孵化演出（7B-b）で扱う
  - 震え `tremble=hold?Math.sin(tm*9)*0.006:0`（L1378）— 削除
  - `pulse=hold?0.9+tremble:...`（L1379）— 縮小をやめる
  - 影の濃さ `hold?0.9:0.75`（L1372）— 体を描かないので影も描かない
  - 殻の `cold:hold===1`、亀裂のアルファ `hold?0.15:...` — 体を描かないので不要になる
- 完了条件：息を止めている間、目が通常と同じ間隔で瞬いていること。縮んだり震えたりしないこと

#### Step 4: 息を吐いた瞬間の戻り
- 息止めが終わったとき、**体（`renderMasterBody` の描画スケール）だけ**をわずかに膨らませてから通常に戻す。0.2〜0.3秒程度
- やり過ごした瞬間の「ふう」を作るための演出。大げさにしないこと
- **光の半径（`master.r`）には一切触らないこと。** 光は既存の `P.grow`（広がる秒数）のカーブでそのまま戻す。`master.r` を一時的に大きくすると、**敵に発見される距離まで変わってしまう**
- 完了条件：息を止めて解除したとき、体がわずかに膨らんでから落ち着くこと。**光は既存の `P.grow` のカーブで `P.r1` へ戻り、`P.r1` を超えないこと**（`releaseBreath()` は `master.idx=1` に戻すため、解除後の目標半径は `P.r2` ではなく `P.r1`）

### チャンク3：光の初期値

#### Step 5: 光の半径を最小近くに下げる
- `P` の光半径の初期値を、実プレイで確認された値へ差し替える
  - 潜伏 `r0`: **0.5**
  - 中 `r1`: **2**
  - 全開 `r2`: **3**
- **上記の値は、現在のスライダーの最小値そのものである。** さらに下げられる余地を作るため、**`SPEC` の最小値を次のとおり引き下げること**
  - `r0`: 最小 0.5 → **0**（潜伏時に完全に光が消える余地を残す）
  - `r1`: 最小 2 → **0.5**
  - `r2`: 最小 3 → **1**
  - `altarR`: 最小 1.5 → **0.5**
  - `altarLit`: 最小 1.5 → **0.5**
- 祭壇が晒す半径・照らす半径の初期値も **1.5** にする
- **最小値を下げた結果、`r0 > r1` や `r1 > r2` という大小の逆転をスライダーで作れるようになる。** 対処は次のいずれかでよく、方式は実装側判断とする
  - スライダー操作時に `0 ≤ r0 ≤ r1 ≤ r2` を保つよう、他の値を連動させる
  - 逆転を許容したうえで、光の半径更新が破綻しないことを保証する
- 完了条件（追加）：`r0` を `r2` より大きくしても、**光の半径の更新が停止したり極端に遅延したりしないこと**。ゲームが操作不能にならないこと
- **敵側の数値（気づく半径、松明が照らす半径、前方視野、巡回速度など）は変更しない。** 光だけを先に確定させる
- 完了条件：ゲーム開始時の**暖色の光と色が届く範囲**が、現在より明確に小さいこと。パネルでさらに下げられること。**`P.sightR`（光らない地形視界、現在7）は変更しないため、地形そのものは従来どおり見える**

## 4. 便全体の完了条件

デバッグモードで遺跡を数階プレイし、以下を確認すること。

1. マスターの**暖色の光と色が届く範囲**が小さくなっている（`P.sightR` による光らない地形視界は従来どおり）

4. パネルで息止めの秒数を変えると、実際の持続時間が変わる

5. 息止めの秒数スライダーを6.0にすると、段階1で6秒・段階2で7.8秒・段階3で9秒になる
