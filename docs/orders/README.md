## 便の分割について

2026-08-08 の設計セッション中に、階数の大幅拡張（10階前後→38〜50階）と支点（プレイヤーが置くチェックポイント）の導入が決まりました。
これにより第7便 v2 の前提が崩れたため、三便に分割しています。

| 便 | 内容 | 状態 |
| --- | --- | --- |
| **7A** | 階数の差し替え／進化の割合判定／断面図の長階数対応／詩と儀式の分離／見せすぎの一掃／真の姿の再配線／周回スケーリング／タブ復帰時の時間流入 | hotfix実装済み・通し検品待ち |
| **7B-a** | デバッグパネルUX／進行度表示／ポーズ／DEV既定値と三状態 | 実装済み・通し検品待ち |
| **7B-b1** | 息止め中の目だけ表現／息止め秒数とCTの調整／光半径初期値 | 実装済み・通し検品待ち |
| **7B-b2** | 息止め中の通常移動比率0〜1／マス単位の速度切替／固有能力の維持 | 実装済み・Kevinの数値確定待ち |
| **7B-b3** | 見失い追跡と周辺捜索／息止め中のマスター座標回避／炎上3秒停止 | 実装済み・Kevinの数値確定待ち |
| **7B-b** | クリア保存の前倒し／地上演出の作り直しと土地の詩／タイトルの卵と孵化／地図トグル廃止とミニマップ／森のコア | 実装済み |
| **7C** | 支点一式（長押し設置・保存の統合・ハート0での復帰） | 実装済み。ハートの階またぎは既定値のまま |

7Aの役割は、**Kevinが遺跡50階を通しでプレイして所要時間を測れる状態を作ること**です。
支点の本数、ハートの持ち越し、階数の妥当性という後続の判断が、この測定を待っています。

## 第7便 v2 から持ち越された項目

破棄した v2 に含まれ、7A では扱わなかった項目です。**7B・7C で必ず回収してください。**

- クリア保存の前倒し（通常クリア分岐で1回だけ登録し、デバッグ地上演出では登録しない）
- 地上クリア演出の作り直しと各土地の詩の表示
- タイトルの卵と孵化
- 地図トグルの廃止と息止め中ミニマップ
- 森のコアの追加
- 特殊敵の初回フラグの永続化
- 演出中のシネマティック化（HUDを隠し、他モードへの上書きを受け付けない）
- 種火連鎖の停止中に真の姿のタイマーを進めない
- 息止めの教えの発火条件（視線が通っていて、かつ息止め中でないこと）
- リセット時の既読キーとボタン表示の初期化
- 女神の教えの既読保存タイミング（表示開始時点→完了時点）

## レビュー体制

発注文は、書き上げてすぐ発射せず、別のAIにコードと照合させてから発射します。

> 設計（Claude）→ レビュー（GPT・scout6と照合）→ 修正版 → 実装（Codex）

このレビューで実際に検出された誤りの例です。

- 存在しない関数名（`drawProgress`／正しくは `drawCrossSection`）
- 既に実装済みの処理を「新規に追加せよ」と書いていた（`dt` の上限）
- 割合から計算した表の値が式と一致していなかった（進化階）
- コードの実態と異なる理由づけ（`difficultyHp` は参照されていないと書いたが、実際は参照されている。ただし敵HPを減らす処理がないため結論は変わらなかった）

発注文にシンボル名や行番号を書くときは、必ずコード検索で裏を取ってください。
