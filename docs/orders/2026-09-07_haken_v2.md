| 決定 | 理由 |

## 3. 実装ステップ

### チャンク1：名前と打つ演出

#### Step 1: 名前の置き換え
- 画面のボタン「支点」→「**ハーケン**」。HUD の `⚑×N` はそのまま（`⚑` を杭の小さな絵にしてもよい）。開発パネル「支点の本数」→「ハーケンの本数」、「支点へ戻るを試す」→「ハーケンへ戻るを試す」、「支点を消す」→「ハーケンを消す」。`markAt` の '支点' → 'ハーケン'。タイトルの「つづきから（遺跡 12階・支点あり）」→「…・ハーケンあり」
- コードの変数名（`pin*`）は変えなくてよい
- **台帳の置き換えは現行仕様の見出し・本文だけ**（GAME_DESIGN の「支点」の節 → 「ハーケン（旧称：支点）」、TASKS・HANDOFF の現行の記述、`REJECTED_IDEAS.md` の現行参照語に旧称注記）。**過去の決定行・過去の発注文は書き換えない**
- 完了条件：画面に「支点」の語が1つも無い。過去の決定行は元のまま

#### Step 2: 打つ演出
- `updatePinHold`（4秒の進行）：`pinHold` が 1・2・3 秒を越えるたびに `tone(880,.05,'square',.06)`＋`tone(1760,.08,'sine',.03,.02)`（カン）、マスターの足元に火花。**火花は専用の配列 `pinSparks`**（橙の小さな粒4〜6個、速度を持って0.3秒で散る）。`markAt` や既存の `sparks` は使わない（祭壇の火花と混ざる）
- **成功の終了処理を分ける**：4秒到達時は `cancelPinHold()` ではなく `completePinHold()` を呼ぶ（進捗を0に戻し、失敗演出は出さない）。`cancelPinHold(reason)` は `reason`＝`'release'`／`'breath'`／`'contact'`／`'silent'`（モード切替などの無音掃除）を受け取る
- 打ち終わり（`completePinHold`→`pinAtMaster(false)`）：**既存の2音（`tone(659,…)`＋`tone(880,…)`）を新しい完了音に置き換える**：`tone(660,.08,'square',.09)`→`tone(1320,.5,'sine',.06,.06)`（カーン＋余韻）。`screenShake=0.25`（既存の揺れ変数、控えめ）、杭の先端の火が 0→1 で灯る（0.4秒）、**ベイビーの光の描画倍率だけ**を一拍 1.25倍→戻す（0.5秒。`master.r`・`illum()`・発見判定には触れない）、画面下の帯（`drawBreathLesson` と同じ黒帯）に「ハーケンを打った」を1.4秒。**女神の窓は使わない**
- 途中失敗（`cancelPinHold(reason)` が `pinHold>0` かつ `reason!=='silent'` で呼ばれたとき）：`tone(330,.12,'triangle',.05)`（カラン）、`pinSparks` だけを消す、帯に「ハーケンが落ちた」を1.0秒。**`reason==='contact'` のときは帯を出さない**（被弾の表示が優先）
- 完了条件：押している間に1秒ごとに音と火花、押し切ると音・揺れ・杭の火・帯の一行。3秒で離すと「カラン」

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：火が絶える・戻る・女神が渡す

#### Step 3: 火が絶える演出（`pinRespawn` を作り直す）
フェーズを固定する（合計 **約6秒**、初回は女神のぶん延びる）：

| フェーズ | 見えるもの | 秒 |
| --- | --- | --- |
| `dim` | 遊び画面のまま、ベイビーの光がしぼんで瞳だけになり、瞳が閉じる。低い音1つ（`tone(110,.9,'sine',.08)`） | 1.2 |
| `candle` | 真っ暗。**画面中央に小さなキャンドル**（`docs/design/candle-mockup.html` の `candle()` から**蝋燭・皿・芯・炎・こぼれ光・煙だけ**を写す。**文字「火が絶えた」の描画部分は移植しない**——次の `text` で出す）。0.35〜0.5秒で炎が細く伸びて**シュッ**と消える（`tone(2400,.06,'sine',.04)` の短い息の音）→ 煙が一筋のぼって薄れる | 1.3 |
| `text` | 「火が絶えた」が静かに浮かぶ（帯ではなく画面中央、`drawPinRespawn` の文字をそのまま）。**初回のみ、ここから Step 4 の女神へ** | 1.0 |
| `return` | 暗闇の中で**ハーケンの火がまず灯る**（杭の位置に小さな火、0.5秒）→ 瞳が開く → 息を吸うように光が広がって階が見える（女神便 v2 の `light` と同じ描き方、2.0秒）。ハートが戻る音は **`tone(523,.1,'triangle',.06)`→`tone(784,.25,'triangle',.07,.1)`**（既存に単独の回復音は無いので新設） | 2.5 |

- **盤面の準備と操作再開を分ける**：`restoreCheckpoint()`／`restartRunFromBeginning()` は今 `mode='play'` とシネマティック解除まで行う。**盤面だけ組む経路**（`prepareCheckpointBoard()` など）に分け、`return` の始まりで盤面を組み、`return` が終わるまで `mode='pinRespawn'` とシネマティックを保つ。終わった瞬間に `mode='play'`、`invuln=2`
- **入力を止める**：キーボードとステージの早期 return 対象に `pinRespawn` を足す。操作再開の直前に `keys.clear()`、`held=false`、長押しタイマーを消す（演出中に押した方向キーで復帰直後に動かないように）
- 1階からやり直す場合（本数0）：`text` の文字を「火が絶えた」→「はじめから」に変える（今と同じ）。`return` は1階の0本目の火から
- 完了条件：ハート0で上の順に見え、演出中は動けず、終わるまで操作できない。2回目以降は女神が出ない

#### Step 4: 初めて火が絶えたとき、女神がハーケンを渡す
- `campaign.hakenGiven`（**`defaultCampaign()` と `normalizeCampaign()` に項目を足す**。足さないと再読込で偽に戻る）が偽のとき、`text` の直後に女神便 v2 の場面を**暗闇のまま**起動する：`dark`＝`haken[0]` → `open`（暗闇に女神だけ。ベイビーは閉じた瞳）→ `talk`＝`haken[1]`→`haken[2]`→`haken[3]`（文字送り、▼、クリックで次）
- **初回の復帰は本数を消費しない**：`afterHeartLoss()` で `hakenGiven` が偽なら `pinsLeft--` を行わない（⚑×5 のまま渡す）。2回目以降は 7C どおり
- **⚑×5 の初表示は Canvas に描く**：女神の場面中は `setCinematic(true)` で HUD（`#log`）が隠れるので、場面専用の表示（`scene.showCount`）を立てて Canvas の右上に「⚑×5」を描く（`haken[1]` の行が出た瞬間、0.4秒でフェードイン、一度光る）。場面が終わったら `campaign.hakenGiven=true; saveCampaign()` して通常の HUD に引き継ぐ
- 場面の終わりは `light` の代わりに Step 3 の `return` へ（女神が光に溶けながらハーケンの火が灯る）
- HUD の ⚑×N とハーケンのボタンは `campaign.hakenGiven` が真になるまで出さない（0本目の自動設置は今どおり動く。見えないだけ）
- `ask`（はい／いいえ）は出さない
- 「進行をリセット」で `hakenGiven` も偽に戻す（`defaultCampaign()` で戻る）
- 完了条件：新規開始 → 初めてハート0 → キャンドル → 「火が絶えた」→ 暗闇に女神「火が絶えても、わたしがまた灯します。」→ 女神が見える → 「これを、あなたに。ハーケンです。」で HUD に ⚑×5 が現れる → 2行 → 女神が溶けてハーケンの火が灯り、階が見える。2回目の死では女神なし

#### Step 5: 開発導線
- 「ハーケンへ戻るを試す」は今どおり（初回なら女神も出る）。「渡す場面をもう一度」ボタン（`campaign.hakenGiven=false; saveCampaign()`）を足す

## 4. 便全体の完了条件
1. 画面から「支点」の語が消え、「ハーケン」に
2. 打つ間の音と火花、打ち切りの音・揺れ・杭の火・帯の一行、途中失敗の「カラン」
3. ハート0：しぼむ → キャンドルがシュッと消えて煙 → 「火が絶えた」→ ハーケンの火 → 瞳 → 光が広がる
4. 初回だけ女神がハーケンを渡し、そのとき初めて ⚑×5 が出る（初回の復帰は消費なし）。渡される前はボタンも E キーも効かない。以後は女神は出ず、復帰で1本減る
5. 正典の詩は不変。追加は `haken` の4行（暫定、最終稿は Kevin）
6. Sol がブラウザで 2・3・4 を確認して HANDOFF に書く
