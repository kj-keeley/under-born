## 1. 決定（設計の答え、Kevin 未確定＝試作）
| 項目 | 新モード（`tap`） |
| --- | --- |
| 合図 | 祭壇の隣に立ち止まると（今の `near&&master.t>=1&&canIgniteNow()`）、祭壇の冷たい火が**一定の拍で脈打つ**。石皿の拍＝**0.28秒**（`P.tapBeat`） |
| 叩く | 脈の山の前後 **±0.09秒**（`P.tapWindow`）の間に **タップ／クリック または Enter**。**叩き＝短いタップ**（`pointerup` までの時間が 0.18秒未満、かつ移動が `P.stick` 未満）。ドラッグ（`held=true` → 移動）は今どおり通す＝指を動かせば祭壇から離れられる（指摘1）。**Enter の `keydown` はリピート（`e.repeat`）を除外**（指摘3）。E はハーケン、スペースは息止めなので使わない |
| 当たり | **1拍につき成功は1回**（その山で成功済みなら2回目は無視。指摘3）。火花が1つ残り、種火が育つ（`tapHits++`）。必要な当たり数 `tapNeed()`＝段階1：**4**、段階2：3、段階3：2、真の姿：**1**（`igniteNeed` の置き換え）。暗火コアは**切り上げで半分**（4→2、3→2、2→1、1→1） |
| 外れ | 拍の外で叩く／山を1回飛ばす → 鈍い音（`tone(180,.08,'square',.05)`）と火花が1つ消える（`tapHits=max(0,tapHits-1)`）。**飛ばしの減算も1拍1回**、その山の前後で成功していれば飛ばしに数えない（指摘3）。**全部は消えない** |
| 点火 | `tapHits>=tapNeed()` で今の点火処理（L1817 の中身：`near.mine=true` 以降）をそのまま呼ぶ |
| 中断 | **既存互換の条件**（指摘5）：隣接が切れる（離れる、祭壇が動き出す）→ 0。住民の接触は**今の被弾処理でリセットされる場合だけ**（無敵中・真の姿では今どおりリセットしない）。息止めの開始は**暗火・息吹なら継続**（`canIgniteNow` が真の間は叩ける）、それ以外は 0。**新モードだけの条件**：点火成功、対象の祭壇が変わった、モード切替 → 0 |
| 逃げる祭壇（指摘4） | **合図も入力も「祭壇が止まっているとき」だけ**（`a.fleeSteps===0`／移動中でない）。祭壇が動き出した瞬間に `tapHits=0`、合図は消える。止まればまた0から。旧モードの条件は変えない |
| 見せ方 | **輪のゲージ（L3025）は新モードでは描かない**。代わりに祭壇の上に「火花の粒」が `tapHits` 個、脈に合わせて小さく揺れる。脈の山で祭壇の火が一瞬明るく（合図） |
| 音 | 脈の山で小さな「チッ」（`tone(1400,.03,'sine',.025)`、合図）。当たり「カッ」（`tone(900,.05,'square',.06)`＋火花）。外れ「ボス」（上） |
| 状態の文 | L4112「祭壇に火を移している」→ 新モードでは「拍に合わせて 火を打つ」（暫定） |
| 切替 | `P.igniteMode='tap'|'wait'`。**既定は `tap`**。開発パネルに「点火：拍／待ち」と「拍の速さ 0.18〜0.5」「必要数 2〜6」 |
| 時計（指摘7） | 拍の時計・判定窓・音・表示は **減速前の共通時計**（`update` の `dt` は種火配下の移動中に 0.85／0.32 倍になるので使わない。`frame` の生の経過秒か `performance.now()` 差分）。ポーズ・演出（`mode!=='play'`）中は止め、戻ったら山の位相を0から再開 |
| 初期化（指摘6） | `tapTarget`・`tapT`・`tapHits`・「この山で成功／飛ばし判定済み」の履歴を**まとめて初期化する関数 `resetTap()`**。呼ぶ場所：対象の祭壇が変わった、`buildFloor`（階移動・復帰・休憩所）、`prepareCheckpointBoard`、モード切替、点火成功、中断 |
| 入力の優先（指摘2） | 既存の場面別入力（ポーズ・会話・女神・穴・休憩所）と **`sparkSelect`（種火の送り先選択）を先に**。叩き入力を受けるのは **通常プレイ中（`mode==='play'`）で、隣接中かつ `canIgniteNow()` かつ祭壇が止まっているとき**だけ。そのとき消費するのは「短いタップ」と Enter のみ |

## 2. 実装ステップ
### チャンク1
#### Step 1: 状態と判定
- `P.igniteMode='tap', P.tapBeat=0.28, P.tapWindow=0.09`。`tapT`（拍の時計）、`tapHits`、`tapTarget`（隣の祭壇）
- L1817 の分岐を `P.igniteMode==='wait'` なら今どおり、`'tap'` なら：隣接中は `tapT+=dt`、山＝`tapT % tapBeat` が 0 をまたぐ瞬間。叩き入力（pointerdown／Enter keydown。**祭壇の隣接中だけ**、他の用途の入力より先に処理し、消費する）が山の ±window なら当たり、外なら外れ。山を window 以上過ぎても叩かなければ「飛ばし」で外れ
- 点火後は `tapHits=0`、次の祭壇でまた0から
#### Step 2: 見せ方と音（§1）
#### Step 3: 開発パネルと状態の文
- 完了条件：1F の祭壇の隣で、脈に合わせて Enter を4回当てると点火。Enter 押しっぱなしでは1回しか当たらない。外すと粒が1つ減る。離れると0。`wait` に切り替えると今の1.4秒待ちに戻る。種火配下の連鎖は操作なしで今どおり。**種火の手動の送り先選択（`sparkSelect`）が今どおり動く**

**ここでチャンク1完了報告。**
