### Kevin の演出（原文。これが仕様）
> 普通はまずはセリフだけをみせて、目覚める前にうとうとしてる中で話しかけられてるとみせて、その後に視界が目覚めたようにひらけて、そこは暗闇の中で女神だけがいる。女神が「ひをともしてくれますか？」とかいって、はい、いいえの選択がでてきて。はいを選ぶと。女神が消えてダンジョンの中にいるのがわかる。

### なぜ「急」だったか（直す側の理解）
v1〜hotfix は、**明るい遊び画面の中に女神が湧いて、いきなり話し、話し終わると消える**だった。ポケモンやマザー2の場面はそうではない。①声が先で姿はあと、②見えるのは話し手だけ、③プレイヤーが自分で返事をする、④相手が消えることが次の場面の始まりになる。この4つが無かった。

- `CANON_POEMS` の既存の本文と改行
- 進化儀式・敵紹介・息止めの教え・敵 AI・光・種火連鎖・マップ生成・地上演出の既存秒数

## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| **声が先。** 真っ暗な画面に、正典の1行目だけが文字送りで出る。まだ何も見えない | 「目覚める前に、うとうとしている中で話しかけられている」 |
| **視界が開く。** 暗闇の中に女神だけが立っている。床も敵も祭壇も見えない | 「視界が目覚めたようにひらけて、そこは暗闇の中で女神だけがいる」 |
| **女神が問う：「火をともしてくれますか？」** はい／いいえ の選択が出る | Kevin の言葉。返事をするのはプレイヤー |
| **はい → ベイビーの火が灯り、光が広がる。女神は光の中に消える。広がった光でダンジョンの中にいると分かる** | 「はいを選ぶと、女神が消えてダンジョンの中にいるのがわかる」。ベイビーの光＝視界、というこのゲームの核と重なる |
| **いいえ → 女神が言い方を変えて食い下がる（3段）。4回目以降は短い一言で繰り返す。ゲームオーバーは無し。3回以上断ったことを覚えておき、あとの場面（初進化・解放）で女神が触れる** | Kevin（9-06）：「ゲームオーバーじゃなくて、3度以上断ると、クリア時とか、あとで女神に『大きくなりましたね』とか『ありがとう』って言われる時に、最初は頼みを断りまくったくせに、ありがとう、とか言われるのは？」。類似作品の型では「言い方を変えて食い下がる（マザー2・Deltarune）」＋「拒否を世界が覚えている（Undertale）」の合わせ技 |

## 2. 台詞（正典＋Kevin の新しい1行）

`CANON_POEMS` に **`ask`** を足す。**本文は Kevin の言葉。最終稿の採否は Kevin（最終決定④）。それまで暫定の文で実装する。**

```js
ask:['火をともしてくれますか？'],   // Kevin 2026-09-06（暫定。最終稿は Kevin）
```

選択肢の文字は `はい`／`いいえ`。

**いいえ の台詞（Claude 草稿。Kevin の案を土台に、女神の声＝送り出す母・説明語なし・画面にある物の語彙で整えた。最終稿は Kevin）**

```js
refuse:[
  ['ほんとうに、ことわるのですか？'],                                          // 1回目
  ['え。……ほんとうに、ですか？'],                                              // 2回目
  ['……まってください。','ごほん。もういちど、いいます。','どうか、小さき火よ。わたしのかわりに……','火を、ともしてくれませんか？'],  // 3回目（1行ずつ文字送り）
  ['……どうか。']                                                               // 4回目以降、これだけを繰り返す
],
```

各段のあとに、もう一度 `はい`／`いいえ`。**ゲームオーバーは無い。**

**断った回数を覚える**：`campaign.refusals`（数）。`はい` を選んだ時点の いいえ の回数を保存する（`saveCampaign`）。3以上なら「断りまくった」扱い。

**あとで触れる台詞（`campaign.refusals>=3` のときだけ。正典の詩の直後に、別の行として1つ足す。Claude 草稿、最終稿は Kevin）**

```js
callback:{
  child:  ['はじめは、あんなに いやだと言っていたのに。'],                      // 初進化「大きくなりましたね、小さな火。／活き活きと、その火で照らすのです。」の直後
  release:['はじめは、{n}度も ことわったのに。','……ありがとう。'],             // 解放「よく頑張りましたね…／…わたしのじまんのこ。」の直後。{n} は断った回数
},
```

**回数は正確に覚えて言う**（Kevin 9-06：「何回断ったか正確に女神が覚えていて、それを最後に『8度もことわったのに』とか言ってくるのがいい」）。`{n}` は `campaign.refusals` を**漢数字**にして入れる（3→三、8→八、10→十、12→十二、25→二十五。`kanjiNum(n)` を1本書く）。初進化の `callback.child` には数を入れない（最後だけ効かせる）。

2回目の進化（`lord`）と変身前（`trueForm`）には足さない（くどくなる）。

## 3. 実装ステップ

### チャンク1：窓と文字送り

#### Step 1: 画面下の窓 `drawTextWindow`
- 画面下 `CS*.70`〜`CS*.96` に黒い窓（塗り `rgba(3,2,7,.92)`、縁 `rgba(232,226,214,.85)` 2px、角丸 `CS*.012`）。左右余白 `CS*.05`
- 文字は `drawPoemLines` と同じフォント、大きさ `CS*.028`、色 `--ink`、左揃え、1行。長い行（31字）は `CS*.90` に収まる
- **文字送り**：1文字 0.045秒。1文字出るごとに `tone(1200,0.02,'square',0.02)`（`audioReady` のとき）。クリック／Enter で残りを一気に出す（ポケモンと同じ）
- 行を出し切ったら右下に「▼」を 0.6秒周期で点滅。もう1回クリック／Enter で次へ
- **選択肢**：窓の右上に小窓（`はい`／`いいえ`、縦2段）。▲▼キーとタップで選ぶ、Enter／クリックで決定。既定は `はい`
- 吹き出し（`drawSpeechBubble`）は**この便で使わなくなる**。残すか消すかは実装側判断

#### Step 2: 場面の骨組み `goddessScene`（v1 の `mode='goddess'` を作り直す）
フェーズを次の順に固定する。各フェーズで**画面に何が見えるか**を守ること。

| フェーズ | 見えるもの | 何が起きる | 秒数 |
| --- | --- | --- | --- |
| `dark` | 真っ暗（`#030207`）。窓だけ | 1行目を文字送り。▼ → クリック | 文字送り＋待ち |
| `open` | 暗闇の中に**女神だけ**（足元に柔らかい光、光輪）。ベイビーは自分の火の点だけ（`renderMasterBody` の `lit=0` 相当の小さな点） | 上下から黒がゆっくり開く（まぶた。1.2秒）。窓は閉じている | 1.2 |
| `ask`（開始のみ） | 同上＋窓 | 「火をともしてくれますか？」を文字送り → 選択肢 | 待ち |
| `talk` | 同上＋窓 | 残りの行（開始なら2行目「さぁ、起き上がって…」、進化なら2行目）を文字送り。▼ → クリック | 待ち |
| `light` | 女神が光に溶けながら、**ベイビーの光が今の半径まで広がる**。広がるにつれて床・壁・祭壇が見えてくる | 女神 alpha 1→0（1.5秒）、ベイビーの光 0→通常（2.0秒、`ubEase`） | 2.0 |
| 終了 | 遊び画面 | `mode='play'`、`invuln=1.2`、`setCinematic(false)` | — |

- `ask` で **いいえ** を選んだら：窓を閉じ、0.6秒の間（女神は立ったまま、瞬きだけ）、`refuse[n]` の行を文字送り（n＝断った回数−1、4回目以降は最後の要素）→ もう一度 `ask` の選択肢へ。回数制限なし。`はい` を選んだら、その時点の いいえ の回数を `campaign.refusals` に保存
- **クリックは「次へ」**。`dark`／`open`／`light` の途中では受け付けない（`open` は飛ばせない：まぶたが開く時間は演出）
- 音：`dark` の始まりに何も鳴らさない（声だけ）。`open` の始まりに低い1音 `tone(262,0.8,'sine',0.04)`。`light` の始まりに上がる3音（`tone(523,.12,'triangle',.06)`, `tone(659,.12,'triangle',.06,.12)`, `tone(784,.4,'triangle',.07,.24)`）

#### Step 3: 開始（1階）への接続
- 今の順（スポット → 女神）を捨てる。**`beginOpeningPoem` から直接 `goddessScene` を `dark` で始める。** 初回スポットライト（`startFirstSpotlight`）は **`light` フェーズに吸収**する（ベイビーの光が広がって世界が見える＝スポットの役目）。`campaign.spotlightSeen` は `light` の終わりで立てる
- 行の割り当て：`dark`＝`opening[0]`「小さき火よ。目を覚ますのです。」／`ask`＝`ask[0]`／`talk`＝`opening[1]`「さぁ、起き上がって。上へ上へいってらっしゃい。」
- 2回目以降の土地（`openingPoemSeen`）も同じ場面を出す（v1 と同じ。クリックで進めるので短い）

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：進化と森

#### Step 4: 初進化・2回目の進化
- `updateEvolutionBlackout` の明けで、**`beginPendingFloor()` は呼ぶが、画面は `dark` のまま**（新しい階は組むが見せない）。`goddessScene` を `dark` で始める：`dark`＝1行目、`open`、`talk`＝2行目（`lord` は1行なので `dark` のあと `open` → `talk` は無しで `light` へ）、`light` で新しい階が見えてくる
- `ask` は出さない（問うのは開始だけ）
- **初進化のときだけ**：`campaign.refusals>=3` なら、`child` の2行のあとに `callback.child` を1行足す（同じ窓、文字送り、▼）
- 儀式スキップ時は今どおり（女神なし、`beginPendingFloor` のみ）

#### Step 5: 森の地上（`drawSurfaceWorld`、`story=true`）
- `campaign.refusals>=3` なら、解放詩2行のあとに `callback.release` の2行を足してから「かくれなくていい」へ
- 地上は「暗闇」ではなく**白い光**で同じ型を作る：`dark` の代わりに画面全体が `rgba(255,236,180,1)` に近い明るさで、窓に解放詩1行目 → `open` で光が引いて地上の絵と女神（左 `W*.16`）が見える → `talk` で解放詩2行目 → 続けて「かくれなくていい」（`trueForm[0]`）→ `light` で女神が光に溶ける → その後に初変身（`transform`／`burst`）
- 既存のタイムライン（`grow`／`transform`／`burst` の秒数）は、女神の場面が終わってから始まるように**後ろへずらす**（秒数そのものは変えない）

#### Step 6: 開発導線・掃除
- 開発パネル「女神を試す」は新しい場面（`dark` から）を起動する
- `drawOpeningPoem`／`mode==='poem'`／`skipOpeningPoem`／`drawSpeechBubble`／hotfix の `arrive`/`leave` は使われなくなる。消すか残すかは実装側判断（消すなら参照も全部）
