## 1. 決定
| 項目 | 内容 |
| --- | --- |
| **ハーケンは拾い物** | 遺跡の壁に、昔の登山者が残したハーケン（金具）が刺さっている。**プレイヤーが持ち歩く杭は無い**。見つけて隣に立ち、**4秒長押しで縄を結ぶ**と、そこが復帰地点になる（今の `pinAtMaster` を「その金具のマス」に対して行う）。どこでも打つ操作（今の E／ボタン長押しで自分の足元）は**廃止** |
| **どの階に出るか（暫定）** | **遺跡だけ**（指摘7。他4土地は開発用なので今の「どこでも打つ」旧挙動をそのまま残す。切替は `curTheme==='ruins'`）。区画（4階）ごとに **2階**にだけ1つずつ。**1F には必ず**（覚える場所）。**出現階の一覧をラン開始時に決めて保存**（指摘1）：`activeRun.pitonFloors=[1, a, b, c, ...]`（区画1は 1F＋2〜4F から1、区画2〜4は各4階から2。`prepareRunFromBeginning`／`startRun` で決める）。`normalizeRun` で復元（整数・範囲・重複除去。無ければ＝旧セーブは**同じ規則で決め直して保存**）。**「非出現階」と「未生成階」を分ける**：出現階かどうかは `pitonFloors` で決まり、位置 `activeRun.pitons[floor]` はその階を初めて作った時に決める（未生成＝キーなし、非出現＝一覧に無い）。休憩所は今の自動杭のまま |
| **どこに出るか** | 床のマスで、①開始位置から歩いて 6 マス以上（`bfs` の歩数） ②祭壇・開始位置に隣接しない ③**壁に接している**（`wallDir` はその壁の向き。金具は壁側に描く） ④`bfs` で開始位置から到達できる。候補から `Math.random` で1つ（位置は保存するので種は不要）。**候補0件なら距離の条件を 6→4→2 と緩め、それでも無ければ「壁に接する」を外す。最後まで無ければその階は非出現に落とし、一覧を更新して保存**（指摘2）。保存：`activeRun.pitons={ [floor]: {x,y,wallDir} }`。**`normalizeRun` の検証は、その階の（反転済みの）盤面で床であること・`wallDir` の先が壁であること・到達できることまで見る**（盤面は `floorShapeFor(floor)` 等で再構築して確認。不正なら削除して次の `buildFloor` で決め直す）。反転階でも同じ規則で新たに決める。**穴（指摘3）**：穴は後から `exitHolePosition()` が決めるので、**穴生成側で「金具のマスと、その隣接マスを避ける」**を足す（候補が無いときだけ隣接を許し、重なりだけは避ける）。**逃げる祭壇（指摘4）**：`fleeAltarCellFree()` で、現在の復帰先に加えて**配置済み金具のマスを除外** |
| **見つけ方** | 金具は暗闇でも**ごく弱く光る**（未点火の燠より弱い、白っぽい金属の光。壁越しには見えない）。息止め中のミニマップに小さな点。隣に立つと HUD のボタンが「**縄を結ぶ**」に変わって有効になる（隣でないときは無効・薄い） |
| **結ぶ（4秒）** | 今の `updatePinHold` の4秒・1秒ごとの音・失敗条件（離す・住民に触れる・息を止める）はそのまま。見せ方だけ変える：**金具に縄が巻き付いていく**（1秒ごとに1巻き、仮のコード描き）。4秒で「キュッ」（`tone(1200,.06,'triangle',.07)`＋`tone(400,.12,'sine',.05,.05)`）と縄が張り、金具に小さな火が灯る（今の杭の火）。帯「**縄を結んだ**」。状態の文「縄を結んでいる」。**8s の断面図カットイン（A）は、盤面を止めずに上部へ小さく 0.8 秒差し込む形に縮める**（`mode='pinTopo'` をやめ、`pinTopoFx={t,...}` として描画だけ。入力を止めない。飛ばしは不要）。**終了処理は描画専用（指摘6）**：`finishPinTopo()` の `mode='play'`・無敵時間の設定は**行わない**（削除）。`pinTopoFx` は `rawDt` で進めて 0.8 秒で消すだけ。**死亡（`afterHeartLoss`）・`buildFloor`・昇階・休憩所・タイトルへ戻るで `pinTopoFx=null`**。ポーズ中は進めない。断面図の杭の印・ずり落ち（C）はそのまま |
| **結び直し** | 「もう結んである」は**現在の復帰先 `activeRun.pin` の座標がその金具と一致するときだけ**（履歴ではない。指摘5）。そのときは4秒なしで帯だけ。別の金具に結ぶと復帰先が移る（今と同じ） |
| **旧セーブの杭（指摘5）** | 8s 以前の手動杭は任意の床にある。**読込時に、その杭が金具の位置と一致しなければ「金具の無い復帰先」として扱う**：復帰先としては有効（そこへ戻る）、床には今の杭の絵で見せる、「もう結んである」判定は不一致なので通常どおり金具で結び直せる。`activeRun.pin.piton=true|false` で識別 |
| **戻ったとき減るもの** | 今の `pinsLeft`（5）をそのまま「**縄の残り**」として使う。戻るたび 1 減り、0 で「はじめから」（今の分岐のまま）。HUD の表示を `⚑×n` → **`縄 ×n`**（仮の文字。絵は見た目スレ）。女神から受け取るまでの扱い（未授与では結べない・HUD に出さない）は今のまま |
| **0本目と休憩所** | 今のまま。0本目（土地に入った時点）は「見えない縄」、休憩所は入った瞬間に結んである。断面図の印も今のまま |
| **開発パネル** | 「ハーケンを出す（この階）」（今の階の候補から1つ置き直す）、「縄 +1」、既存の「授与済みにする」「ハーケンへ戻るを試す」「渡す場面をもう一度」はそのまま |
