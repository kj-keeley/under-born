## 1. 決定事項（Kevin 9-12 確定）と実装の形

| 決定 | 形 |
| --- | --- |
| 通貨＝火の粒。住民が正気に戻るとき1体1粒 | `freeFloorResidents` で解放した数だけ、住民からベイビーへ小さな粒が飛ぶ。**支給済みの記録は `activeRun.sparkGranted={floor:true}`（`RUN_KEY` に保存）**。同じランで同じ階を再攻略（死亡・復帰）しても**支給しない**（指摘2）。残高 `campaign.room.sparks` は `PROGRESS_KEY` に保存。「はじめから」「周回」でランが新しくなれば `sparkGranted` は空（残高は残る）。「進行をリセット」で残高も消える |
| HUD に粒の数 | ハートの隣に「✦ n」。0 のときも出す |
| 粒の飛ぶ絵 | **`flyHearts` とは別の配列 `sparkFly`** を持ち、`update` だけでなく **`updateAscent`（解放演出 `pulse` 中）でも更新・描画**する（指摘3：`freeFloorResidents` 直後は `mode='won'` で `update` が呼ばれない）。色 `255,196,107`、小さい |
| 売り手＝わかれみち型 | 休憩所で、火の左隣（`x:4,y:5`）に**部屋の主（わかれみち型）が1体、常に**座る（`e.host=true`、解放の列とは別枠、`restTalked` の判定から**分離**して何度でも話せる。指摘5）。品を足元に並べる。隣で Enter →「なにに する？」の窓（`openRestDialogue` の型、▶ を上下、Enter／クリックで決定）。**店の選択入力は「クリックで会話を閉じる」より先に処理**する |
| 品5つ | 水（1粒）／太陽の絵（8）／月の絵（8）／星空の絵（8）／鳥の模型（8）。**所有済みの絵は「かざる」（無料、残高に関係なく選べる。掛け替え）**、**所有済みの鳥は「もっている」で選べない**（指摘6）。粒が足りない品は薄く表示して選べない |
| 鉢の木5つ | 部屋の上の壁際（**`y:1`、`x:2,4,6,8,10`**。部屋は横12マスで内側は x 1〜10。指摘4）に鉢。水1回で左から順に1段（芽→若葉→小木→木→花、0〜4）。全部花なら「水」は選べない |
| 絵 | 部屋の壁（上辺の中央）に1枚。太陽／月／星空の仮の絵（丸・三日月・点の散り） |
| 鳥の模型 | 棚（**`x:8,y:2`**）に小さな鳥の形。**座席の配置は鉢の行（y:1）・棚・主の席（4,5）・石（6,5）を避けて組み直す**（指摘4） |
| 保存 | `campaign.room={sparks:0,trees:[0,0,0,0,0],owned:{sun:false,moon:false,stars:false,bird:false},picture:null}`。`defaultCampaign`／`normalizeCampaign` に追加。**周をまたいで残る**。「進行をリセット」で消える |

## 3. 実装ステップ

### チャンク1：粒と保存
#### Step 1: `campaign.room` と粒
- `defaultCampaign`／`normalizeCampaign`（L337）に `room` を追加（上の形）。`freeFloorResidents` で粒が飛び `sparks` に加算・保存。HUD に「✦ n」
- 完了条件：階クリアで粒が飛び、HUD の数が住民の数だけ増える。再読み込みで残る

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：部屋
#### Step 2: 部屋の主と品
- `buildRestRoom`（L1393）で、火の左隣にわかれみち型を1体固定で座らせる（`e.host=true`、解放の列とは別枠）。足元に品の仮の絵
- 隣で Enter → 品の窓（5行＋「やめる」）。▶ を上下で動かしクリック／Enter で決定。買うと `sparks` が減り、`trees`／`owned`／`picture` を更新・保存。台詞（§2）を1行

#### Step 3: 鉢・絵・鳥の描画
- 鉢5つ（段に応じて仮の形：芽＝緑の点、若葉＝葉2枚、小木＝幹＋丸、木＝幹＋大きな丸、花＝丸に点）。壁の絵1枚。棚の鳥。**描画は通常の盤面描画（`restRoom` のとき）と `drawRestInteraction` に足す**（`drawRestRoom` は存在しない。指摘4）
- 完了条件：買うと即座に部屋に現れる。再読み込みでも残る。「進行をリセット」で消える

#### Step 4: 開発導線（指摘7）
- 開発パネル「粒を＋20」「部屋をリセット（開発用）」。**リセットは開発専用の例外**（正典「進行をリセットでだけ消える」は本番の話）。押すと `confirm` で確認し、`campaign.room` を初期値に戻す
- **休憩所プレビュー（`restPreview`）では店を開けない**（本番の残高を書き換えない）

## 4. 便全体の完了条件
1. 階クリアで粒が飛び、HUD に数
2. 休憩所でわかれみち型から買える。鉢が育ち、絵が掛かり、鳥が乗る

4. 正典の詩は不変
