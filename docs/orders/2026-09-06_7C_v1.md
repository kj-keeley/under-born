## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| 支点は**プレイヤーが自分で置く復帰地点**。ボタン**長押し4秒**で設置。途中で手を離す、敵に触れる、息を止める、のどれかで進捗ゼロ | GAME_DESIGN。「4秒間動けないことそのものが制限」「息止め3秒なので、息を止めながら刺し切れない」 |
| 設置場所に制限なし。**同時に有効な支点は1つ**（新しく刺すと前のは消える） | 正典「直近の支点に戻る」 |
| **土地に入った時点で0本目が自動で立つ**（消費しない）。手持ちは**5本（暫定）**。土地をまたいで持ち越さない | 正典「手持ちは3〜5本（測定後に決定）」。未測定なので緩い側の5を暫定に。開発パネルで 3〜5 を切り替えられるようにする |
| **ハート0 → 直近の支点に戻る**。支点を1本消費。**その階の頭から**。祭壇は消灯、敵は再配置。ハートは**刺した時点の数**に戻る | 正典＋DECISIONS 09-03 暫定（刺した時点） |
| **手持ちが0でハート0 → その土地の1階から**。そのとき手持ちは初期本数に戻る（暫定） | 正典「支点がない状態でハート0 → その土地の1階から」。本数が戻らないと1階から二度と進めないので暫定で戻す |
| **刺した瞬間に保存する**。ブラウザを閉じても、タイトルに「つづきから」が出て直近の支点から再開 | 正典 |
| 今の「火が絶えた」ゲームオーバー（`mode='lost'`）は**支点への復帰に置き換える** | 支点導入後の正典「0になると失敗（支点導入後は支点へ戻る）」 |

## 3. 実装ステップ

### チャンク1：支点を刺す・戻る

#### Step 1: 状態と保存
- ラン状態 `run={theme, floor, core, pinsLeft, pin:{floor, hearts, x, y}|null}` を持つ。`pinsLeft` の初期値は開発パネルの `P.pinCount`（既定 **5**、3〜5）
- **`RUN_KEY='underborn_run_v1'`** で `localStorage` に保存（`PROGRESS_KEY`／`saveCampaign`（L325〜328）と同じ書き方。`normalizeRun` で検証）。保存するのは**支点を刺した瞬間**と**0本目が立った瞬間**だけ。他のタイミングでは書かない
- `startTheme`（L724）で `pinsLeft=P.pinCount`、`pin=null`。1階の盤面が組めた直後（`reset()` の後）に**0本目を自動で立てる**（`pin={floor:1,hearts,x:master.tx,y:master.ty}`、`pinsLeft` は減らさない）→ 保存
- 土地をクリア（通常クリア経路 L1357）したら `RUN_KEY` を消す。「進行をリセット」でも消す

#### Step 2: 刺す操作（長押し4秒）
- 画面のボタン「支点」を息止めボタンの隣に足す（`breathBtn`、L3080〜 の `pointerdown`／`pointerup`／`pointerleave` と同じ型）。キーボードは **E** の長押し
- 押している間 `pinHold` が 0→4 秒。**マスターは動けない**（移動入力を無視。息止めの操作ロックと同じ扱い）。マスターの周りに進捗の輪（`glow` の系統、amber）を描く
- **中断条件**（進捗ゼロに戻す）：ボタンを離す／敵に触れてハートが減る（L1374〜の被弾処理）／息止めを始める（`holdBreath` L3033）。息止め中はそもそも押せない
- 4秒に達したら：`pinsLeft--`、`pin={floor,hearts,x,y}`、保存、足元に**支点の印**（小さな杭に火。`mChip` と `glow` で描く。以後その階にいる間は見える）。音：`tone(659,.12,'triangle',.07)`＋`tone(880,.3,'triangle',.08,.12)`
- `pinsLeft===0` のときはボタンを薄くして押せない。HUD（L2872〜）にハートの隣で**残り本数**を「⚑×3」のように出す
- 完了条件：4秒押し切ると本数が減って印が立つ。3秒で離すと何も起きない。押している途中で敵に触れると進捗が消える。息止め中は押せない

#### Step 3: ハート0で支点へ戻る
- L1377〜1381 の `mode='lost'; show('火が絶えた',…,'もう一度')` を置き換える：
  - `pin` があり `pinsLeft>0`：`pinsLeft--`、**0.8秒の暗転**（「火が絶えた」の文字だけ）→ `floor=pin.floor`、`hearts=pin.hearts`、`buildFloor()`（L860。祭壇消灯・敵再配置はこれで起きる）→ マスターを `pin.x,pin.y` に置く → 印を描く → `invuln=2` → 遊び。保存は**しない**（支点の保存内容は変わらない）
  - `pin` があり `pinsLeft===0`、または `pin` が無い：**その土地の1階から**。`floor=1`、`hearts=3`、`pinsLeft=P.pinCount`（暫定）、0本目を立て直して保存。暗転の文字は「火が絶えた」→「はじめから」
- 敵紹介・女神の場面は再生しない（既読フラグはそのまま）
- 完了条件：支点を刺した階より上でハート0になると、その階の頭に戻り、ハートが刺した時の数、本数が1減っている。本数0でハート0なら1階から

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：つづきから・掃除

#### Step 4: タイトルの「つづきから」
- タイトル（`showTitle`）で `RUN_KEY` があれば、開始操作のあとに「**つづきから（遺跡 12階・支点あり）**」「はじめから」の2択を出す（コア選択の前）。「つづきから」＝`run` を読み、`startTheme(run.theme)` のあと `pin.floor` の盤面を組んで `pin` の位置・ハートで再開。**開始の女神の場面は出さない**（`openingArmed=false` の経路）。「はじめから」＝`RUN_KEY` を消して今どおり
- ポーズの「中断してタイトルへ」（`quitPausedRun`、L3211）は今どおり**保存しない**。次にタイトルへ来たときは直近の支点から
- 完了条件：支点を刺してからリロードしても、タイトルに「つづきから」が出て、その階の頭・その位置・そのハートで再開する

#### Step 5: 開発パネル
- 「支点の本数」3〜5（既定5）＝`P.pinCount`
- 「支点へ戻るを試す」ボタン（ハートを0にする）
- 「支点を消す」ボタン（`RUN_KEY` 削除）

#### Step 6: 正典の文言
- HUD の本数表示、ボタンの文言「支点」、暗転の文字「火が絶えた」「はじめから」。**新しい詩は足さない**

## 4. 便全体の完了条件
1. 4秒の長押しで支点が立ち、本数が減る。途中で離す／被弾／息止めで進捗が消える
2. ハート0で直近の支点の階の頭へ戻る（祭壇消灯・敵再配置・ハートは刺した時）。本数0なら1階から
3. 刺した瞬間に保存され、リロード後「つづきから」で同じ所から
4. 土地クリアで支点の保存が消え、次の土地で本数が初期に戻る
5. 女神便・7B-b の場面と正典の詩は不変
6. Sol がブラウザで 1〜3 を確認して HANDOFF に書く

## 5. スコープ外
- 支点の本数の**確定**（測定後、Kevin）、階数の再調整
- ハートの階またぎ持ち越し（既定値のまま）
- `DEV_DEFAULT=false`、エンディングの詩、ロゴ
