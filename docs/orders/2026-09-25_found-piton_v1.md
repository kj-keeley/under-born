## 1. 決定
| 項目 | 内容 |
| --- | --- |
| **ハーケンは拾い物** | 遺跡の壁に、昔の登山者が残したハーケン（金具）が刺さっている。**プレイヤーが持ち歩く杭は無い**。見つけて隣に立ち、**4秒長押しで縄を結ぶ**と、そこが復帰地点になる（今の `pinAtMaster` を「その金具のマス」に対して行う）。どこでも打つ操作（今の E／ボタン長押しで自分の足元）は**廃止** |
| **どの階に出るか（暫定）** | 区画（4階）ごとに **2階**にだけ1つずつ（どの2階かはランの種で決める。**1F には必ず**＝覚える場所）。休憩所は今の自動杭のまま（入った瞬間に結んである扱い）。他の階には無い＝「たまにある」 |
| **どこに出るか** | 床のマスで、①開始位置から歩いて 6 マス以上 ②祭壇・穴・開始位置に隣接しない ③**壁に接している**（金具は壁側に描く） ④`bfs` で開始位置から到達できる。候補から種で1つ。**ランの保存に階ごとの位置を持つ**（`activeRun.pitons={ [floor]: {x,y,wallDir} }`、初めてその階を作った時に決めて保存。`normalizeRun` で検証：整数・盤面内・不正なら削除して次の `buildFloor` で決め直す）。反転階（区画内の左右反転）でも同じ規則で新たに決める |
| **見つけ方** | 金具は暗闇でも**ごく弱く光る**（未点火の燠より弱い、白っぽい金属の光。壁越しには見えない）。息止め中のミニマップに小さな点。隣に立つと HUD のボタンが「**縄を結ぶ**」に変わって有効になる（隣でないときは無効・薄い） |
| **結ぶ（4秒）** | 今の `updatePinHold` の4秒・1秒ごとの音・失敗条件（離す・住民に触れる・息を止める）はそのまま。見せ方だけ変える：**金具に縄が巻き付いていく**（1秒ごとに1巻き、仮のコード描き）。4秒で「キュッ」（`tone(1200,.06,'triangle',.07)`＋`tone(400,.12,'sine',.05,.05)`）と縄が張り、金具に小さな火が灯る（今の杭の火）。帯「**縄を結んだ**」。状態の文「縄を結んでいる」。**8s の断面図カットイン（A）は、盤面を止めずに上部へ小さく 0.8 秒差し込む形に縮める**（`mode='pinTopo'` をやめ、`pinTopoFx` として描画だけ。入力を止めない。飛ばしは不要）。断面図の杭の印・ずり落ち（C）はそのまま |
| **結び直し** | 同じ金具にもう一度結ぶことはできる（意味はないので帯だけ「もう結んである」、4秒は要らない＝即時）。別の金具に結ぶと復帰先が移る（今と同じ） |
| **戻ったとき減るもの** | 今の `pinsLeft`（5）をそのまま「**縄の残り**」として使う。戻るたび 1 減り、0 で「はじめから」（今の分岐のまま）。HUD の表示を `⚑×n` → **`縄 ×n`**（仮の文字。絵は見た目スレ）。女神から受け取るまでの扱い（未授与では結べない・HUD に出さない）は今のまま |
| **0本目と休憩所** | 今のまま。0本目（土地に入った時点）は「見えない縄」、休憩所は入った瞬間に結んである。断面図の印も今のまま |
| **開発パネル** | 「ハーケンを出す（この階）」（今の階の候補から1つ置き直す）、「縄 +1」、既存の「授与済みにする」「ハーケンへ戻るを試す」「渡す場面をもう一度」はそのまま |
