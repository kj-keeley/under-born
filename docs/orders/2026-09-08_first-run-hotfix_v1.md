## 1. 直す3点

### Fix 1: 女神から受け取るまで、床とミニマップにハーケンを出さない
- 原因：土地開始で0本目が自動で打たれ（`activeRun.pin`）、床の描画 L2437 とミニマップ L2537 が `campaign.hakenGiven` を見ていない。7f までは小さな杭で目立たなかったが、7g で本物の絵になり「最初から落ちている」ように見える
- 直し：L2437 と L2537 の条件に `campaign.hakenGiven&&` を足す。0本目の**仕組み**（保存・復帰）は今どおり動く。見えないだけ（ハーケン便の「渡されるまで HUD に出さない」と同じ方針）
- 完了条件：新規開始（`localStorage` 空）で1階に絵が無い。初めて火が絶えて女神から受け取った後、その階に打つと絵が出る

### Fix 2: 「はい／いいえ」のカーソルが移動キーで動く
- 原因：L3561 が `ArrowUp`／`ArrowDown` だけ。遊びの移動は WASD＋矢印4方向（L3571）なので、W/S や左右で動かしても反応しない。再現済み：`ArrowDown` は動く、`s`・`ArrowRight` は動かない
- 直し：
  - `ArrowUp`／`W`／`w`／`ArrowLeft`／`A`／`a` → 上（はい）、`ArrowDown`／`S`／`s`／`ArrowRight`／`D`／`d` → 下（いいえ）
  - **マウスを乗せた行にカーソルが動く**（`goddessChoiceRects` を `pointermove` でも見る）。クリックはその行を選ぶ（今どおり）
  - 上の項目で `ArrowUp` を押したとき、はいのまま止まる（回り込まない）。下も同様。**回り込みをやめる**（2択で回り込むと「動いてない」と誤解する）
- 完了条件：新規開始の「ともしてくれますか？」で W/S・A/D・矢印4方向すべてで▶が動き、マウスを「いいえ」に乗せると▶が移る

### Fix 3: 光の穴が暗闇に隠れない
- 原因：穴の描画 L2098 が床の描画パスにあり、暗闇レイヤー（L2348〜）の下。ベイビーの光の外だと見えない
- 直し：L2098 の穴の描画を、ハーケン（L2437「暗闇の上でも見失わない」）と同じ暗闇の**上**へ移す。光の輪の外でも見える強さ（`glow` ＋楕円）。ミニマップの印は今どおり
- 完了条件：最後の祭壇を灯したあと、離れた所からでも穴が見える
