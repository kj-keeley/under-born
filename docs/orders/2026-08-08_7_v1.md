## 1. ゴール

1周目を「真の姿なしの純ステルスラン」として成立させる。未解禁の要素とデバッグ機能が初見プレイヤーの目に一切入らなくなり、詩は儀式と重ならず単独で読める。攻略はクリアした瞬間に保存され、途中で閉じても再開できる。

## 2. 決定事項と理由

| 決定 | 理由 |
|---|---|
| 詩と進化儀式を分離し、儀式完了→一拍の暗転→詩単独→階開始の順にする | 現状 `drawEvolution` 内で詩を描いており（L2809-2812）、演出の上に文字が乗って両方死んでいる。詩は単独で読ませる |
| 真の姿の入手を遺跡クリア→**森クリア**に移す。使用可は**2周目から** | 1周目は隠れることしかできない旅にする。真の姿は旅の帰結であって道具ではない |
| 真の姿の性能は**固定値**（持続20秒／CT60秒） | 解放数連動・累計参照・完成体はすべて廃止。森クリア直後に弱体化するパラドックスが仕様ごと消える |
| 真の姿は**初期コア限定** | 女神の「小さき火」の宛先は初期コア個人。覚醒コアの取り分は固有技のほう |
| 未解禁のダンジョン・コア・機能は**存在ごと非表示** | グレー表示は「まだ何かある」と教えてしまう。解禁の瞬間に初めて現れる |
| 選べる対象が1つしかない選択画面は表示しない | 初回に選択の余地のない画面を2枚通過させている。開幕のテンポを止めるだけ |
| クリア確定を最終階クリアの瞬間に前倒す | 現状は8〜19秒の地上演出完了後に保存（L2229）。演出中に閉じると10階分の攻略が消える |
| 地図の常時トグルを廃止し、**息止め中のみミニマップ表示**にする | 敵の行動パターン観察をやめたため常時参照が必須でなくなった。息止めは光が消える＝視覚が閉じる行動なので、代わりに地図感覚が開くのは筋が通る。全体像は連鎖時のズームアウトで見える |
| 周回の敵HP上昇を**削除**する | `difficultyHp`（L731）はどこからも参照されていない死んだ変数。敵HPを減らす処理自体が存在しない |
| 周回の敵数を**毎レベル+1**にする | 現状は `Math.floor((loopLevel-1)/2)` で2レベルごとに1体。Lv2とLv3が同数でダイヤルの手応えがない |
| 土地クリアの詩の語り手を**土地自身**にする（女神ではない） | 女神は送り出す声で、宛先を持つ。土地の詩は誰にも呼びかけない。声を分けることで両方が立つ |
| 遺跡には土地の詩を置かない | 遺跡だけが人工物で、土地としての声を持たない。例外ではなく規則 |
| 森だけ土地の詩→女神の詩と続ける | エンディングで二つの声が初めて重なる。旅の始点（女神のみ）と終点（両方）で挟む |

## 3. 棄却した案

**再提案しないこと。**

| 案 | 棄却理由 |
|---|---|
| 完成体（森クリアで初期コアが最終形態化） | 概念ごと廃止。真の姿は固定値 |
| 真の姿の性能を解放土地数・覚醒コア数に連動させる | 周回開始時に解禁数が1へ戻るため、完成直後に弱くなる |
| 遺跡クリアで初変身シーンを見せる | 森＝エンディングへ移設済み |
| 未解禁要素をグレーアウトで見せる | 存在ごと非表示にする |
| 周回で敵の体力を上げる | 敵HPを減らす処理を新設する必要があり、純修正便の枠を超える |
| 地図をボタンでいつでも開けるようにする | 上記の通り廃止 |
| 土地の詩を女神の声で書く | 語り手を分ける決定を採用済み |
| 森コアの呼称「豊穣」「恵み」 | 既存コア（転位／暗火／霞）が現象の名で揃っているのに対し、受け手側から見た語になる |
