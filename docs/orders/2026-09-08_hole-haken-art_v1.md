## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| **最後の祭壇を灯しても自動では上がらない**。`pulse`（脈打ち・住民が正気に戻る）だけ起きて遊びに戻り、**最後に灯した祭壇の上に光の穴**が開く。プレイヤーが穴のマスに入ると `rise` から今の昇階演出 | Kevin「自分で選んでる感」。シレン系は階段に自分で乗る。実利：住民が正気に戻った安全な階で、ハーケンを打ってから上がれる |
| 穴が開いている間、住民は正気のまま（追わない）。祭壇は消されない | 「クリア済みの階」を壊さない。ハーケンを打つ余裕のため |
| **ハーケンの絵＝C**。渡す場面・HUD・床の3か所で同じ絵 | Kevin「Cかな」。類似作品の型：手に入れた瞬間に絵、以後同じ絵 |
| 渡す場面：`haken[1]`「これを、あなたに。ハーケンです。」の行で、**女神とベイビーの間に絵が浮かび、行が終わると HUD の ⚑ の位置へ飛んで数字になる** | ゼルダ・ホロウナイトの「物が出る → 持ち物へ」。今は文字だけ |

## 3. 実装ステップ

### チャンク1：上る穴

#### Step 1: 最後の祭壇を灯したあと
- L1677 の `startAscent()` を分ける：`pulse` 相当（全祭壇の脈打ち・`freeFloorResidents()`・既存の2音）を 0.6秒だけ `mode='won'` で見せたら **`mode='play'` に戻す**（`setCinematic(false)`、`invuln` 少し）。`ascentAnim` は捨てる
- 最後に灯した祭壇のマスに **`exitHole={x,y,t}`** を置く。見た目：縦長の楕円の光（`rise` の穴と同じ絵）が床に開き、ゆっくり脈打つ。ミニマップにも印
- 帯（`drawBreathLesson` の黒帯）に「光の穴が開いた」を1.4秒。**女神の窓は使わない**
- 穴が開いている間：住民は `freed` のまま、祭壇の消灯なし、ハーケンは打てる、息止めも可
- 完了条件：最後の祭壇を灯す → 脈打ち → 遊びに戻り、祭壇の上に穴。住民は追ってこない。ハーケンを打てる

#### Step 2: 穴に入る
- ベイビーが `exitHole` のマスに着いた瞬間（`master.t>=1`）、`exitHole=null` にして **`startAscent()` を `rise` から**（`pulse` は飛ばす。`ascentAnim.phase='rise'`）。以降は今どおり `floorCard` → `open`
- 節目・最終階の扱いは今どおり（最終階は `startFinalRelease` を今のまま。**最終階は穴を出さず自動**。理由：土地クリアは儀式なので選ばせない）
- 進化階（`stageForFloor(floor+1)>stageForFloor(floor)`）も今どおり **穴を出さず `nextFloor()` 直行**（儀式が先）
- 開発パネル「穴を出す」（現在階をクリア扱いにして穴を置く）
- 完了条件：穴に入ると浮上 → カード → 新しい階。穴に入らなければいつまでも上がらない

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：ハーケンの絵

#### Step 3: 床と HUD
- §2 の `drawHaken` を作り、床の杭（L2386〜の `mChip`）を置き換える。炎は縄の結び目の上
- HUD の `⚑` を絵に（`drawHakenCount` の暗闇 HUD と、L3292 の通常 HUD の両方）
- 完了条件：打った床に縄つきハーケンが立ち、HUD に同じ絵と `×N`

#### Step 4: 渡す場面
- 女神の `talk` で `haken[1]` の行が出た瞬間（今 `showCount` を立てている所）：女神とベイビーの間（画面中央やや下）に z=6 の絵が 0.3秒でふわっと現れ（下から少し浮く、`glow`）、行の文字送りが終わってクリックされたら **0.5秒で HUD の位置へ縮みながら飛び**、着いたところで `⚑×5` が光って現れる（今の `showCount` のフェードをこの着地に合わせる）
- 完了条件：「これを、あなたに。ハーケンです。」で絵が浮かび、クリックで HUD へ飛んで数字になる
