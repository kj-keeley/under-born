## 1. 決定事項と理由

| 決定 | 理由 |
| --- | --- |
| **名前を「支点」→「ハーケン」に**。画面のボタン・HUD・開発パネル・暗転の文字・台帳の語をすべて置き換える | Kevin：「支点って名前が分かりづらい」「名前は賛成（ハーケン）」。登山の比喩（GAME_DESIGN「登山のプロテクションに相当」）そのもの。類似作品の復帰地点は世界の中の物の名前（篝火・ベンチ・ロープ） |
| **打つ演出**：4秒の間、1秒ごとに「カン」と金属の音と火花。打ち終わりに一段大きい音・ごく小さい画面の揺れ・杭に火が灯る・ベイビーの光が一拍脈打つ・帯に一行「ハーケンを打った」。途中失敗は「カラン」と火花が消える | 類似作品（ダクソ・Hollow Knight・Spelunky）はどれも「置く行為」を1〜2秒の儀式にしている。今は刺しても何も起きた感じがしない（Kevin） |
| **火が絶える演出**：ベイビーの光がしぼんで瞳だけ → 真っ暗 → **画面中央に小さなキャンドルが現れ、炎がシュッと消えて煙が一筋のぼる** → 「火が絶えた」→（初回だけ女神）→ ハーケンの火が灯り、瞳が開き、息を吸うように光が広がって階が見える | Kevin のイメージ（キャンドル）。類似作品は死の瞬間に体が変わり、暗闇に言葉か旋律が1つ、戻るときに目覚めの動作がある。今の0.8秒暗転は軽い（Sol も指摘） |
| **初めて火が絶えたときだけ、女神がハーケンを渡す**（暗闇の声 → 女神だけ → 一言 → HUD に ⚑×5 が初めて出る → 消える）。2回目以降は女神なし | 類似作品の型：最初の1本は始めからある（篝火）、意味は初めて死んで分かる、説明は一度だけその瞬間に一行（ポケモンの母）。4秒長押しという独自操作は絵だけでは伝わらない |
| **HUD の ⚑×N は、女神から渡されるまで出さない**（0本目は見えない） | 「渡す」場面を本物にするため。渡される前に本数が見えていると渡す意味が無い |

## 3. 実装ステップ

### チャンク1：名前と打つ演出

#### Step 1: 名前の置き換え
- 画面のボタン「支点」→「**ハーケン**」。HUD の `⚑×N` はそのまま（`⚑` を杭の小さな絵にしてもよい）。開発パネル「支点の本数」→「ハーケンの本数」、「支点へ戻るを試す」→「ハーケンへ戻るを試す」、「支点を消す」→「ハーケンを消す」。`markAt` の '支点' → 'ハーケン'。タイトルの「つづきから（遺跡 12階・支点あり）」→「…・ハーケンあり」
- コードの変数名（`pin*`）は変えなくてよい
- 完了条件：画面に「支点」の語が1つも無い

#### Step 2: 打つ演出
- `updatePinHold`（4秒の進行）：`pinHold` が 1・2・3 秒を越えるたびに `tone(880,.05,'square',.06)`＋`tone(1760,.08,'sine',.03,.02)`（カン）、マスターの足元に火花（橙の小さな粒4〜6個が0.3秒で散る。`markAt` の系統でよい）
- 打ち終わり（`pinAtMaster(false)`）：`tone(660,.08,'square',.09)`→`tone(1320,.5,'sine',.06,.06)`（カーン＋余韻）、`screenShake=0.25`（既存の揺れ変数。値は控えめ）、杭の先端の火が 0→1 で灯る（0.4秒）、ベイビーの光半径を一拍だけ 1.25倍→戻す（0.5秒）、画面下の帯（`drawBreathLesson` と同じ黒帯）に「ハーケンを打った」を1.4秒。**女神の窓は使わない**
- 途中失敗（`cancelPinHold` が `pinHold>0` で呼ばれたとき）：`tone(330,.12,'triangle',.05)`（カラン）、火花が消える、帯に「ハーケンが落ちた」を1.0秒。敵接触で失敗したときは帯を出さない（被弾の表示が優先）
- 完了条件：押している間に1秒ごとに音と火花、押し切ると音・揺れ・杭の火・帯の一行。3秒で離すと「カラン」

**ここでチャンク1完了報告。以降は続行。**

### チャンク2：火が絶える・戻る・女神が渡す

#### Step 3: 火が絶える演出（`pinRespawn` を作り直す）
フェーズを固定する（合計 約4.5秒、初回は女神のぶん延びる）：

| フェーズ | 見えるもの | 秒 |
| --- | --- | --- |
| `dim` | 遊び画面のまま、ベイビーの光がしぼんで瞳だけになり、瞳が閉じる。低い音1つ（`tone(110,.9,'sine',.08)`） | 1.2 |
| `candle` | 真っ暗。**画面中央に小さなキャンドル**（`docs/design/candle-mockup.html` の `candle()` を写す：蝋燭・皿・芯・炎・炎のこぼれ光）。0.35〜0.5秒で炎が細く伸びて**シュッ**と消える（`tone(2400,.06,'sine',.04)` の短い息の音）→ 煙が一筋のぼって薄れる | 1.3 |
| `text` | 「火が絶えた」が静かに浮かぶ（帯ではなく画面中央、`drawPinRespawn` の文字をそのまま）。**初回のみ、ここから Step 4 の女神へ** | 1.0 |
| `return` | 暗闇の中で**ハーケンの火がまず灯る**（杭の位置に小さな火、0.5秒）→ 瞳が開く → 息を吸うように光が広がって階が見える（女神便 v2 の `light` と同じ描き方、2.0秒）。ハートが戻る音（既存の回復音） | 2.5 |

- 1階からやり直す場合（本数0）：`text` の文字を「火が絶えた」→「はじめから」に変える（今と同じ）。`return` は1階の0本目の火から
- 完了条件：ハート0で上の順に見え、2回目以降は女神が出ない

#### Step 4: 初めて火が絶えたとき、女神がハーケンを渡す
- `campaign.hakenGiven`（保存）が偽のとき、`text` の直後に女神便 v2 の場面を**暗闇のまま**起動する：`dark`＝`haken[0]` → `open`（暗闇に女神だけ。ベイビーは閉じた瞳）→ `talk`＝`haken[1]`→`haken[2]`→`haken[3]`（文字送り、▼、クリックで次）→ **`haken[1]` の行が出た瞬間に HUD の ⚑×5 を初めて表示**（0.4秒でフェードイン、`⚑` が一度光る）→ `light` の代わりに Step 3 の `return` へ（女神が光に溶けながらハーケンの火が灯る）→ `campaign.hakenGiven=true; saveCampaign()`
- HUD の ⚑×N は `campaign.hakenGiven` が真になるまで描かない（0本目の自動設置は今どおり動く。見えないだけ）
- `ask`（はい／いいえ）は出さない
- 「進行をリセット」で `hakenGiven` も偽に戻す
- 完了条件：新規開始 → 初めてハート0 → キャンドル → 「火が絶えた」→ 暗闇に女神「火が絶えても、わたしがまた灯します。」→ 女神が見える → 「これを、あなたに。ハーケンです。」で HUD に ⚑×5 が現れる → 2行 → 女神が溶けてハーケンの火が灯り、階が見える。2回目の死では女神なし

#### Step 5: 開発導線
- 「ハーケンへ戻るを試す」は今どおり（初回なら女神も出る）。「渡す場面をもう一度」ボタン（`hakenGiven` を偽に戻す）を足す
