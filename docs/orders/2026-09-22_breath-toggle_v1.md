# UNDERBORN 実装指示：息止めトグル便 v1 — 息止めを「押し続け」から「1回押す／もう1回で戻す」へ＋叩き中のカメラ寄せを外す

> 設計：Claude（2026-09-22）。Kevin の 8q 実プレイ感想（`docs/design/feedback-2026-09-17.md` 9-22、`DECISIONS.md` 9-22）：「ボタンを押し続けながら画面をクリックできない。9F の密集はかなり難しい」「最初に灯籠をクリックすると画面が少しずれる」。Kevin 9-22「おｋ」（トグル）。レビュー用 Sol は飛ばす（操作の置き換え＋1行の直し）。

## 0. 対象
- `game/underborn_scout8q.html`（`260862e`）→ **出力 `game/underborn_scout8r.html`**、`BUILD_VERSION='v0.8r'`
- 行番号は 8q：`holdBreath` L4522、`releaseBreath` L4530、keydown L4569、keyup L4583、`breathBtn` L4588〜、マスター長押し L4689・L4712、ポーズ復帰 L4737、時間切れ L1918、HUD 文言 L128・L5043・L5252、`tapFocus` L2791
- 壊すな指定：息止めの効果そのもの（光が消える・時間 `breathMax()`・CT `breathCd`・時間切れで自動解除・息止め中は通常コアで点火不可・暗火/息吹の例外・息吹の点火で自動解除 L1834・ハーケン中止 `cancelPinHold('breath')`）、石皿・灯籠の判定、`CANON_POEMS`

## 1. 決定
| 項目 | 内容 |
| --- | --- |
| 型 | **トグル**（ステルスゲームのしゃがみと同じ）。1回の操作で息を止め、もう1回で吐く。押し続けは不要。止めている間の上限と時間切れの自動解除、CT は今のまま |
| 操作（統一） | **Q／スペースの keydown**（`e.repeat` は無視）、**HUD の息ボタンの pointerdown**、**マスターの長押し（0.35秒、L4689）**の3つは全部「トグル」＝`toggleBreath()`：`breathHeld` なら `releaseBreath()`、でなければ `holdBreath()`。**keyup・pointerup・pointerleave では何もしない**（L4583・L4589・L4590・L4712 の `releaseBreath()` を外す）。ドラッグ移動・タップ点火・ハーケンの操作は変えない |
| ポーズ | ポーズ中に押しても切り替えない（今の `mode!=='play'` ガードのまま）。`pausedBreathReleasePending`（キーを離したまま復帰したときの解除）は不要になるので削除。ポーズ復帰後も止めたままが続く |
| 文言 | HUD ボタン：止めていないとき「**息を止める**」、止めているとき「**息を吐く**」（＋残り秒は今の表示規則のまま）。L128・L5043・L5252 の「(長押し)」を外す。開発ヘルプ L4827 の「Q/スペースで息を止める」はそのまま（押し続けの記述があれば削る） |
| 教え（1F の息止めの教え） | 台詞は変えない（`CANON_POEMS`）。操作説明の文字があれば「押す」に |
| **カメラ寄せを外す**（感想2） | `tapFocus`（L2791）の「祭壇とベイビーの中点」を**やめる**：叩いている間もカメラはベイビー追従のまま。残すのは `keepIgnitionView`（連鎖ズームを引かせない・`chainView` を0へ戻す）と、配下への追従より点火中を優先する部分だけ。`tapFx` の寄り（4%）は中心をベイビーにする |

## 2. 完了条件
1. 新規開始 → 1F：Q を1回押すと光が消え、もう1回で戻る。押し続けても1回分。時間切れで自動解除、CT 中は押しても止まらない
2. HUD ボタンを1回タップで止まり、文言が「息を吐く」に。もう1回で戻る。指を離しても戻らない
3. マスター長押しで止まり、指を離しても戻らない。その後の短いタップ（点火）とドラッグ移動は今どおり
4. **9F：息を止めて灯籠の隣まで行き、Q で吐いてから灯籠を叩ける**（マウス・スマホの両方の流れが成立）。息止め中は通常コアで点火不可のまま。暗火は息止め中も点火可
5. 石皿・灯籠を叩き始めてもカメラが動かない（灯籠の揺れ始め、石皿の1打目）。連鎖ポーズ中は今どおり引かない
6. ポーズ→復帰で息止めが継続。息吹コアの点火で自動解除は今どおり
7. `CANON_POEMS` 不変。`HANDOFF.md` に確認を書く
