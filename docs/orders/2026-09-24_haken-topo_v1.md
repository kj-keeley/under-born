## 1. 決定
| 項目 | 内容 |
| --- | --- |
| **A. 打つ瞬間のカットイン** | `completePinHold` の完了音「カーン」と同時に、**画面の上から断面図の板が差し込む**（黒の半透明の帯＋`drawCrossSection` を中央に、0.2秒でスッと降りる。暗転なし、盤面は後ろに見えたまま）。板が止まった 0.1秒後、**今の階の行に大きなハーケン（仮の絵：床の縄つきハーケン C を2.5倍に拡大した形）が上から「ドン」と打たれる**（0.15秒で落ちて着地、小さな揺れ `screenShake=0.25`、`tone(660,.08,'square',.09)` は既存の完了音を流用しそのまま）。着地後、**下にある直近の杭（0本目・休憩所の自動杭・前に打った杭）と縄で結ぶ線を 0.3秒で引く**（直近が無ければ縄なし）。合計 1.0秒見せて 0.2秒で上へ戻る。**この間は操作を止める**（`keys.clear()`、`held=false`、ポインタ無視。石皿・灯籠の判定は `mode!=='play'` 扱いで止まる＝新しい `mode='pinTopo'` を足すのが簡単。`tapClock`／`swingT` は止まる）。**飛ばせる**（Enter／タップで即戻る）。0本目の自動杭・休憩所の自動杭では出さない（手で打ったときだけ） |
| **断面図の杭の印** | `drawCrossSection` に「杭のある階」を渡し、その行の右に小さな杭の印（仮：`⚑` 相当の小さな三角）を常に描く。階カード・記録の石・旅の果てにも自然に出る。データ源：`activeRun.pin`（直近）と、**打った階の履歴 `activeRun.pinFloors=[...]`（新設、`saveRun` に含める。復帰で階が巻き戻っても履歴は残す）** |
| **C. 火が絶えたときのずり落ち** | `updatePinRespawn` の `candle` の後、`text`（「火が絶えた」）の後に **新しい phase `topo`（1.4秒）**：真っ暗のまま中央に断面図。**小さな火（ベイビーの光の点）が今の階の行から直近のハーケンの階の行まで、行を1つずつ落ちる**（1行 0.12秒、途中で「カタ」`tone(220,.04,'square',.03)`）。杭の行で止まり、杭が一瞬光る（`tone(1320,.3,'sine',.05)`）。同じ階に杭があるときは落ちずに杭が光るだけ（0.5秒）。そのあと今どおり `beginPinReturn()`（初回で女神が渡す場面のときは、女神の**後**に `topo` を入れる＝`haken` の phase の後）。**飛ばせない**（今の演出と同じ扱い） |
| **開発パネル** | `hakenGiftBtn`「渡す場面をもう一度」の**隣に「ハーケンを授与済みにする」を追加**：`campaign.hakenGiven=true; saveCampaign(); pinBtn.style.display='';`（本数は今の手持ち）。**Kevin 9-24 の混乱の対策**：授与は初めて火が絶えたときに女神から、が正規の道で、開発パネルから直接は無かった |
| 文言 | 帯「ハーケンを打った」は今のまま。断面図の上に小さく「遺跡 {n}F」（今の階カードと同じ書式） |

## 2. 実装ステップ
### チャンク1：A（カットイン）＋杭の印＋履歴＋開発ボタン
- 完了条件：1F で手動で打つ → 断面図が差し込み、1F の行に大きな杭、0本目の杭（同じ階なら縄なし）、1秒で戻る。操作は止まり、Enter で飛ばせる。休憩所の自動杭では出ない。階カード・記録の石・旅の果ての断面図に杭の印が出る。開発ボタンで授与済みになり HUD にハーケンが出る
**ここでチャンク1完了報告。**
### チャンク2：C（ずり落ち）
- 完了条件：3F で打ち、5F でハート0 → キャンドル → 「火が絶えた」→ 断面図で火が 5→4→3 と落ちて 3F の杭で止まり光る → 杭の火→瞳→光で 3F の頭から。同じ階なら落ちない。初回（女神が渡す）は女神の後に出る
