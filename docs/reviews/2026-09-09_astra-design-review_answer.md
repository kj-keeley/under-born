# 遺跡16階版・設計レビュー回答（2026-09-09）

資料・8aの関連コード・類似作品の公式説明によるレビュー。今回は動かして見た評価ではなく、飽きる階と緊張は未検証の仮説。新規開始の画面確認・通し計測は実施していない。
前提差：DECISIONS.md 148〜151行には、依頼文より後の「遺跡単独で完結・エンディング移設」等の決定がある。以下は16階内の構成を評価し、8aにその後の決定が実装済みとは扱わない。

## 1. 飽きる所はどこか

最初の候補は **3〜4F、次は7〜8F**。区画の初階で地形と住民を覚えたあと、同じ点火順が通るなら残りが反復になる。初進化も9Fまで来ない。
根拠：**類似作品からの推論**。Spelunky Classicは地形がプレイごとに変わる一方、8aの `floorShapeFor`（384行〜）は区画内で同じ地図を返す。住民配置の変化だけで攻略が変わるかは未確認。[公式説明](https://spelunkyworld.com/original.html)

## 2. 1つだけ足りないもの

**道中の状況によって、攻略の方針を選び直す理由**。区画ごとに見た目と敵が変わっても、毎回同じ順で灯せば済むなら、16階への短縮だけでは作業感が残る。
根拠：**類似作品**。Spelunky Classicは変化する地形・手持ちの道具・財宝と危険を攻略に絡める。借りたいのはこの判断の変化であり、16という階数そのものではない。[公式説明](https://spelunkyworld.com/original.html)

## 3. 休憩になっているか

**仕様上はなっている**。危険と計時が止まり、回復・保存が済み、退出を自分で決められる。戻した住民を見ることも、この作品固有の休む理由になる。
根拠：**類似作品との比較からの推論＋仕様確認**。player-journey §4の町・休憩部屋との比較では、買い物がなくても安全と再出発は満たす。実際に安堵できる間かは未検証。追加・削除案は末尾。

## 4. 点火無料で緊張が消えたか

**無料化だけで消えたとは言えない**。点火中は姿を晒し、接触で減るので、「灯したいが近づけない」という緊張は残せる。
根拠：**類似作品からの推論＋コード確認**。Spelunkyの移動・探索に伴う危険と同様、行為の代金より周囲の危険が判断を作る。ただし8aは連鎖回復（1536行）・毎階最低3（1029行）・休憩所全快が重なり、被害が軽くなる可能性がある。[公式説明](https://spelunkyworld.com/original.html)

## 5. 撤回するなら1つ

**②のうち「区画内4階を同一地図で通す」固定を撤回候補にする**。4区画×4階は残し、覚えた道順を繰り返すだけになる部分を疑う。
根拠：**類似作品からの推論**。Spelunkyの地形変化が担う判断の更新は、区画数を合わせるだけでは得られないため。撤回は提案であり、決定ではない。[公式説明](https://spelunkyworld.com/original.html)

## 提案（決定はKevin）

- まず既存16階の通しで「前階と同じ点火順で済んだ階」「息止めや迂回が必要だった場面」を記録する。同じ地図でも判断が変わっていれば、地図変更は不要。
- 反復が確認された場合だけ、同一区画の後半1階で祭壇・巡回の配置を変え、点火順を考え直す最小案から試す。全面的なランダム生成や装備システムは必要ない。
- 休憩所は今の内容を維持し、現段階では足すもの・削るものはなし。安全・全快・保存は既存仕様で揃っているため、新しい場面演出の調査・提案は今回行わない。
- 緊張不足が確認された場合は、点火代金を復活させず、保留中の「通常昇階時の最低3保証を外し、ハートを持ち越す」を最初の比較候補にする。連鎖回復・休憩所全快は残し、敵強化と同時に変更しない。

比較資料の注意：player-journey §4は作品・版・ダンジョンを一括りにしており、「1本16〜30階／30〜40分」は今回の根拠に使わない。16階の妥当性は本作の通しで確かめる。
