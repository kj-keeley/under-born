# UNDER BORN / アンダーボーン

Claude・GPT・Codexと共同で制作するゲームプロジェクトです。

## 現在の段階

- ゲーム本体は実装済みで、ブラウザで遊べる
- 正典のゲームファイルは `game/underborn_scout8a.html`
- 遺跡16階便まで実装済み。4区画×4階で地図・色・住民が変わり、4F・8F・12F後に休憩所、9F・13F進入時に進化する
- 次は遺跡16階の長い通しプレイと手触り確認。その後に他4土地の階数・区画構成を決め、一般配布用の `DEV_DEFAULT=false` 戻しを行う
- GitHubを、AI間で共有する正典（信頼する最新版）として使用

## 最初に読むファイル

1. `AGENTS.md` — 全AI共通の作業ルール
2. `GAME_DESIGN.md` — ゲーム仕様
3. `DECISIONS.md` — 確定事項と判断理由
4. `REJECTED_IDEAS.md` — 却下・棚上げした案
5. `TASKS.md` — 現在と次の作業
6. `HANDOFF.md` — 直近の引き継ぎ
7. `docs/orders/README.md` — 発注文の有効版と履歴

## 基本の進め方

1. 作業開始前にGitHubの最新版を取得する。
2. 上記ファイルを読み、変更前に計画と対象範囲を説明する。
3. 当面はClaudeとCodexを同時に作業させず、一人ずつ進める。
4. 作業後に仕様・決定・タスク・引き継ぎを更新する。
5. 書き込み可能な担当がコミットしてGitHubへ反映し、次のAIはその続きから始める。

ClaudeなどGitHubへ書き込めない担当は、完成ファイルまたはdiffと引き継ぎを提出し、Codexが内容を確認して反映します。

秘密情報、APIキー、パスワード、個人情報はコミットしません。
- `docs/design/player-journey.md`：プレイヤーが経験する通しの流れ（プロット形式）、未検証の一覧、類似ゲームの通しの構成との比較（2026-09-09）
