1. `AGENTS.md` — 全AI共通の作業ルール

## 基本の進め方

1. 作業開始前にGitHubの最新版を取得する。
2. 上記ファイルを読み、変更前に計画と対象範囲を説明する。
3. 当面はClaudeとCodexを同時に作業させず、一人ずつ進める。
4. 作業後に仕様・決定・タスク・引き継ぎを更新する。
5. 書き込み可能な担当がコミットしてGitHubへ反映し、次のAIはその続きから始める。

ClaudeなどGitHubへ書き込めない担当は、完成ファイルまたはdiffと引き継ぎを提出し、Codexが内容を確認して反映します。

秘密情報、APIキー、パスワード、個人情報はコミットしません。
